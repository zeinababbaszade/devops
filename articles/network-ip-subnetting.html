IP Address چیست؟

IP Address یک آدرس منطقی است که برای شناسایی یک Interface یا Endpoint در شبکه استفاده می‌شود.

در IPv4، Address از 32 بیت تشکیل شده است. برای خوانایی بیشتر این 32 بیت به چهار بخش 8 بیتی تقسیم می‌شوند.

IPv4 
192.168.1.20

هر بخش می‌تواند عددی بین 0 تا 255 داشته باشد.

IPv4 چگونه ساخته شده است؟

هر IPv4 Address در واقع 32 بیت است. مثلاً:

IPv4 
192.168.1.20

اگر آن را به Binary تبدیل کنیم، چیزی شبیه این می‌شود:

Binary 
11000000.10101000.00000001.00010100

Subnet Mask مشخص می‌کند کدام قسمت مربوط به Network و کدام قسمت مربوط به Host است.

Subnet Mask چیست؟

Subnet Mask ابزاری است که مشخص می‌کند چه تعداد بیت از IP متعلق به Network و چه تعداد بیت متعلق به Host است.

یکی از Subnetهای بسیار رایج:

Example 
255.255.255.0

این Mask معادل:

CIDR 
/24

است.

CIDR چیست؟

CIDR مخفف Classless Inter-Domain Routing است.

در CIDR، عدد بعد از Slash تعداد بیت‌های Network Portion را مشخص می‌کند.

CIDR Subnet Mask تعداد کل Addressها
/24 255.255.255.0 256
/25 255.255.255.128 128
/26 255.255.255.192 64
/27 255.255.255.224 32

برای بسیاری از Subnetهای IPv4 معمولی، دو Address برای Network و Broadcast رزرو می‌شوند. بنابراین تعداد Hostهای قابل استفاده معمولاً:

Formula 
Usable Hosts = 2^(Host Bits) - 2

Network Address چیست؟

Network Address آدرسی است که خود Network را مشخص می‌کند. در یک Subnet معمولی IPv4، Host Bits در Network Address برابر صفر هستند.

مثلاً در:

Example 
192.168.1.20/24

Network Address برابر است با:

Network 
192.168.1.0

Broadcast Address چیست؟

Broadcast Address آخرین Address یک Subnet است و برای Broadcast در همان Subnet استفاده می‌شود.

برای:

Network 
192.168.1.0/24

Broadcast:

Broadcast 
192.168.1.255

Host Range

در مثال:

Example 
192.168.1.0/24

Network Address:

Network 
192.168.1.0

Broadcast:

Broadcast 
192.168.1.255

بنابراین Hostهای معمولی:

Host Range 
192.168.1.1 - 192.168.1.254

یعنی 254 Address قابل استفاده برای Hostها داریم.

چند مثال مهم

مثال اول — /24

Network 
192.168.10.0/24
  • Network: 192.168.10.0
  • First Host: 192.168.10.1
  • Last Host: 192.168.10.254
  • Broadcast: 192.168.10.255
  • Usable Hosts: 254

مثال دوم — /26

در /26 تعداد Addressها برابر 64 است.

Subnet 
192.168.1.0/26

Subnet اول:

  • Network: 192.168.1.0
  • Hosts: 192.168.1.1 تا 192.168.1.62
  • Broadcast: 192.168.1.63

Subnet بعدی از:

Next Network 
192.168.1.64/26

شروع می‌شود.

مشاهده IP در Linux

برای مشاهده IP سیستم:

Ubuntu 
ip addr

مثلاً اگر ببینی:

Example 
inet 192.168.1.20/24

یعنی Interface دارای IP 192.168.1.20 با Prefix Length برابر /24 است.

چیزی که از این مرحله یاد گرفتم

  • IPv4 از 32 بیت تشکیل شده است.
  • CIDR مشخص می‌کند چند بیت مربوط به Network است.
  • Subnet Mask و CIDR دو روش برای بیان مرز Network و Host هستند.
  • هر Subnet معمولاً Network Address و Broadcast Address دارد.
  • Host Range بین Network و Broadcast قرار می‌گیرد.
  • با کوچک‌تر شدن Subnet، تعداد Hostهای قابل استفاده کاهش پیدا می‌کند.
