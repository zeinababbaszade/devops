LINUX

مدیریت فایل‌ها و دایرکتوری‌ها در Linux

در این مقاله یاد می‌گیریم چگونه در Linux فایل‌ها و دایرکتوری‌ها را ایجاد، کپی، جابه‌جا، تغییر نام و حذف کنیم.

مقدمه

یکی از مهم‌ترین مهارت‌ها در کار با Linux، توانایی مدیریت فایل‌ها و دایرکتوری‌ها از طریق Terminal است.

در محیط‌های DevOps دائماً با فایل‌های Configuration، Logها، Scriptها، فایل‌های Application و دایرکتوری‌های مختلف سروکار داریم.

بنابراین قبل از اینکه وارد مباحث پیشرفته‌تر DevOps شویم، باید کار با فایل‌ها و دایرکتوری‌ها را به‌خوبی یاد بگیریم.

1. ایجاد دایرکتوری با mkdir

برای ایجاد یک دایرکتوری در Linux از دستور mkdir استفاده می‌کنیم. 

mkdir myfolder

با اجرای این دستور، دایرکتوری myfolder در مسیر فعلی ساخته می‌شود.

می‌توانیم چند دایرکتوری را هم‌زمان ایجاد کنیم: 

mkdir folder1 folder2 folder3

اگر بخواهیم چند دایرکتوری تو در تو ایجاد کنیم، می‌توانیم از گزینه -p استفاده کنیم: 

mkdir -p projects/devops/linux

در این حالت اگر دایرکتوری‌های والد وجود نداشته باشند، Linux آن‌ها را نیز ایجاد می‌کند.

2. ایجاد فایل با touch

برای ایجاد یک فایل خالی می‌توانیم از دستور touch استفاده کنیم. 

touch notes.txt

همچنین می‌توانیم چند فایل را هم‌زمان ایجاد کنیم: 

touch file1.txt file2.txt file3.txt

برای مشاهده فایل‌های ایجادشده: 

ls -la

3. مشاهده محتوای فایل با cat

دستور cat برای نمایش محتوای فایل‌های متنی بسیار کاربردی است. 

cat notes.txt

برای نوشتن یک متن داخل فایل می‌توانیم از echo استفاده کنیم: 

echo "Hello Linux" > notes.txt

حالا محتوای فایل را بررسی می‌کنیم: 

cat notes.txt
نکته:

علامت > محتوای قبلی فایل را جایگزین می‌کند.

اما >> متن جدید را به انتهای فایل اضافه می‌کند. 

echo "Linux is important for DevOps" >> notes.txt

4. کپی کردن فایل با cp

برای کپی کردن فایل از دستور cp استفاده می‌کنیم. 

cp notes.txt backup.txt

در این مثال، یک نسخه کپی‌شده از notes.txt با نام backup.txt ایجاد می‌شود.

برای کپی کردن فایل داخل یک دایرکتوری: 

cp notes.txt myfolder/

برای کپی کردن یک دایرکتوری به همراه محتویات آن، معمولاً از گزینه -r استفاده می‌کنیم: 

cp -r myfolder backupfolder

5. جابه‌جایی فایل با mv

دستور mv برای جابه‌جایی فایل‌ها و دایرکتوری‌ها استفاده می‌شود. 

mv notes.txt myfolder/

این دستور فایل notes.txt را به دایرکتوری myfolder منتقل می‌کند.

6. تغییر نام فایل با mv

جالب است بدانیم که در Linux برای تغییر نام فایل دستور جداگانه‌ای وجود ندارد.

از همان دستور mv استفاده می‌کنیم: 

mv notes.txt linux-notes.txt

در این حالت فایل تغییر مکان نداده است؛ فقط نام آن تغییر کرده است.

7. حذف فایل با rm

برای حذف فایل از دستور rm استفاده می‌کنیم. 

rm notes.txt

برای حذف یک دایرکتوری به همراه محتویات آن: 

rm -r myfolder
هشدار مهم:

در استفاده از rm بسیار دقت کنید.

فایل‌هایی که با این دستور حذف می‌شوند معمولاً وارد Recycle Bin نمی‌شوند و ممکن است بازیابی آن‌ها بسیار دشوار یا غیرممکن باشد.

8. پیدا کردن فایل‌ها با find

دستور find برای پیدا کردن فایل‌ها و دایرکتوری‌ها بسیار کاربردی است. 

find . -name "notes.txt"

علامت . یعنی جستجو از دایرکتوری فعلی شروع شود.

برای پیدا کردن تمام فایل‌های متنی: 

find . -name "*.txt"

9. تشخیص نوع فایل با file

دستور file می‌تواند نوع واقعی یک فایل را بررسی کند. 

file notes.txt

این دستور در زمان Troubleshooting و بررسی فایل‌هایی که نوع آن‌ها مشخص نیست بسیار مفید است.

10. کار با چند فایل با Wildcard

در Linux می‌توانیم از Wildcardها برای کار با چند فایل به‌صورت هم‌زمان استفاده کنیم.

یکی از مهم‌ترین Wildcardها علامت * است. 

ls *.txt

این دستور تمام فایل‌هایی را که پسوند .txt دارند نمایش می‌دهد.

دقت کنید:

قبل از استفاده از دستورات حذف همراه با Wildcard، بهتر است ابتدا با ls بررسی کنید که دقیقاً چه فایل‌هایی Match می‌شوند.

11. تمرین عملی

حالا می‌خواهیم یک محیط کوچک برای تمرین بسازیم.

مرحله اول — ساخت پروژه

cd ~

mkdir -p devops-lab/linux/files

مرحله دوم — ورود به دایرکتوری

cd ~/devops-lab/linux/files

مرحله سوم — ایجاد فایل‌ها

touch notes.txt
touch commands.txt
touch backup.txt

مرحله چهارم — نوشتن اطلاعات

echo "Linux File Management" > notes.txt

echo "mkdir" > commands.txt
echo "touch" >> commands.txt
echo "cp" >> commands.txt
echo "mv" >> commands.txt

مرحله پنجم — مشاهده فایل‌ها

ls -la

cat notes.txt
cat commands.txt

مرحله ششم — ساخت نسخه پشتیبان

cp notes.txt notes-backup.txt

مرحله هفتم — تغییر نام

mv notes-backup.txt backup-notes.txt

مرحله هشتم — پیدا کردن فایل‌ها

find . -name "*.txt"
تمرین پیشنهادی:

قبل از رفتن به مقاله بعدی، تمام دستورات این بخش را روی Ubuntu خودت اجرا کن.

سعی کن بعد از انجام تمرین، یک فایل جدید به نام devops-notes.txt ایجاد کنی و چند دستور Linux که یاد گرفته‌ای داخل آن بنویسی.

Cheat Sheet

دستور کاربرد
mkdir ایجاد دایرکتوری
touch ایجاد فایل خالی
cat نمایش محتوای فایل
cp کپی کردن
mv جابه‌جایی یا تغییر نام
rm حذف فایل یا دایرکتوری
find جستجوی فایل و دایرکتوری
file تشخیص نوع فایل
