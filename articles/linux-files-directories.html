مقدمه

بعد از آشنایی با Terminal و مفاهیم پایه Linux، قدم بعدی این است که بتوانم فایل‌ها و Directoryها را واقعاً مدیریت کنم. در کارهای DevOps تقریباً همیشه با فایل‌های Configuration، Log، Script و Directoryهای سرویس‌ها سروکار داریم.

💡 هدف این مقاله این است که عملیات روزمره روی فایل‌ها را روی Ubuntu تمرین کنم؛ از ساختن و کپی کردن تا جابه‌جایی، حذف و پیدا کردن فایل‌ها.

ساخت Directory

برای ساخت Directory از mkdir استفاده می‌کنیم.

Terminal
mkdir project

اگر بخواهیم چند Directory را هم‌زمان بسازیم:

Terminal
mkdir linux docker networking

ساخت فایل

با touch می‌توانیم یک فایل خالی ایجاد کنیم.

Terminal
touch notes.txt

همچنین می‌توانیم چند فایل را یک‌جا بسازیم:

Terminal
touch commands.txt config.txt README.md

کپی فایل و Directory

دستور cp برای کپی کردن استفاده می‌شود.

Terminal
cp notes.txt notes-backup.txt

برای کپی کردن یک Directory همراه با محتویات آن معمولاً از گزینه -r استفاده می‌کنیم.

Terminal
cp -r linux linux-backup

جابه‌جایی و تغییر نام

دستور mv هم برای جابه‌جایی و هم برای تغییر نام فایل یا Directory استفاده می‌شود.

Terminal
mv notes.txt linux/

برای تغییر نام:

Terminal
mv linux/notes.txt linux/linux-notes.txt

حذف فایل و Directory

برای حذف فایل از rm استفاده می‌کنیم.

Terminal
rm notes-backup.txt

برای حذف Directory خالی:

Terminal
rmdir project

برای حذف یک Directory به همراه محتویات آن می‌توان از rm -r استفاده کرد.

⚠️ دستور rm را با دقت استفاده کن. مخصوصاً rm -r می‌تواند تعداد زیادی فایل را حذف کند و معمولاً مسیر برگشت ساده‌ای ندارد.

پیدا کردن فایل‌ها

دستور find یکی از ابزارهای مهم مدیریت سیستم است. می‌توانیم بر اساس نام، نوع و معیارهای دیگر فایل‌ها را جست‌وجو کنیم.

Terminal
find . -name "*.txt"

دستور بالا فایل‌های متنی را از Directory فعلی و زیرشاخه‌های آن پیدا می‌کند.

Terminal
find ~/devops-lab -type f -name "notes.txt"

Wildcardها

علامت * برای تطبیق چند کاراکتر استفاده می‌شود.

Terminal
ls *.txt

مثلاً دستور بالا فایل‌هایی را که پسوند .txt دارند نمایش می‌دهد.

تمرین عملی: مدیریت فایل‌های DevOps

🧪 تمرین

این تمرین را در Ubuntu اجرا کن:

Ubuntu Terminal
cd ~/devops-lab
mkdir -p linux/files
cd linux/files
touch commands.txt notes.txt config.txt
echo "Linux file management" > notes.txt
cp notes.txt notes-backup.txt
mkdir scripts
mv commands.txt scripts/
find . -type f
ls -la
ls -la scripts
cat notes.txt

در پایان باید بتوانی محل فایل‌ها و محتوای notes.txt را بررسی کنی.

Linux File Management Cheat Sheet

Commandکاربرد
mkdirساخت Directory
touchساخت فایل خالی
cpکپی فایل
cp -rکپی Directory و محتویات
mvجابه‌جایی یا تغییر نام
rmحذف فایل
rmdirحذف Directory خالی
findجست‌وجوی فایل و Directory

چیزی که از این مرحله یاد گرفتم

  • ساختار فایل‌ها و Directoryها را بهتر مدیریت می‌کنم.
  • می‌توانم فایل‌ها را کپی، جابه‌جا، تغییر نام و حذف کنم.
  • با find می‌توانم فایل‌ها را در مسیرهای مختلف پیدا کنم.
  • قبل از اجرای دستورات حذف، باید مسیر و هدف دستور را بررسی کنم.
