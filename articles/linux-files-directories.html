Linux Files & Directories

Learn how to create, copy, move, rename and delete files and directories in Linux.

Introduction

Working with files and directories is one of the most important skills in Linux.

As a DevOps engineer, you will constantly work with configuration files, logs, scripts, application files and directories.

In this article, we will learn how to manage files and directories from the Linux terminal.

1. Creating Directories

The mkdir command is used to create a directory. 

mkdir myfolder

We can also create multiple directories at once: 

mkdir folder1 folder2 folder3

To create nested directories, we can use the -p option: 

mkdir -p projects/devops/linux

The -p option creates parent directories if they do not already exist.

2. Creating Files

The touch command can be used to create an empty file. 

touch notes.txt

We can create multiple files at once: 

touch file1.txt file2.txt file3.txt

Check the files with: 

ls -la

3. Reading Files

The cat command displays the contents of a text file. 

cat notes.txt

We can create a file and write content into it using the echo command: 

echo "Hello Linux" > notes.txt

The content can then be displayed: 

cat notes.txt

4. Copying Files

The cp command is used to copy files. 

cp notes.txt backup.txt

Now we have two files: 

ls -la

To copy a file into another directory: 

cp notes.txt myfolder/

To copy an entire directory, we use the -r option: 

cp -r myfolder backupfolder

5. Moving and Renaming Files

The mv command is used both for moving and renaming files.

Rename a file

mv notes.txt linux-notes.txt

Move a file

mv linux-notes.txt myfolder/

Linux does not have a separate command specifically for renaming files. The mv command handles both operations.

6. Deleting Files

The rm command is used to delete files. 

rm file.txt

To remove a directory and its contents: 

rm -r myfolder
Important:

Be very careful with rm. Linux normally does not provide a Recycle Bin when using rm from the terminal.

Always check your current directory and the command before deleting files.

7. Finding Files

The find command is useful for searching files and directories. 

find . -name "notes.txt"

The dot means that the search starts from the current directory.

We can also search for all text files: 

find . -name "*.txt"

8. Identifying File Types

Linux does not rely only on file extensions to determine what a file actually contains.

The file command can help identify the type of a file. 

file notes.txt

This command is especially useful when troubleshooting unknown files.

9. Wildcards

Wildcards allow us to work with multiple files at once.

The * character represents zero or more characters. 

ls *.txt

This command lists all files ending with .txt.

Another example: 

rm *.tmp
Be careful:

Wildcards can match many files. Always use ls first if you are not sure what will be matched.

10. Practical Linux Lab

Now let's build a small project structure for our DevOps learning environment.

Step 1 — Create the project

cd ~

mkdir -p devops-lab/linux/files

Step 2 — Enter the directory

cd ~/devops-lab/linux/files

Step 3 — Create some files

touch notes.txt
touch commands.txt
touch backup.txt

Step 4 — Add some content

echo "Linux File Management" > notes.txt
echo "mkdir" > commands.txt
echo "touch" >> commands.txt
echo "cp" >> commands.txt
echo "mv" >> commands.txt

Step 5 — Read the files

cat notes.txt
cat commands.txt

Step 6 — Create a backup

cp notes.txt notes-backup.txt

Step 7 — Rename the backup

mv notes-backup.txt backup-notes.txt

Step 8 — Inspect the directory

ls -la

Step 9 — Find text files

find . -name "*.txt"

At this point you have practiced creating, reading, copying, moving, renaming and finding files.

Linux File Management Cheat Sheet

Command Purpose
mkdir Create a directory
touch Create an empty file
cat Display file contents
cp Copy files or directories
mv Move or rename
rm Remove files
find Search for files
file Identify file type

What I Learned

  • Move and rename files.
  • Delete files and directories.
  • Search for files with find.
  • Use wildcards to work with multiple files.
