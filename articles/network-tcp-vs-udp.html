TCP و UDP چیستند؟

TCP و UDP دو پروتکل مهم در Transport Layer هستند. این لایه مسئول انتقال داده بین Applicationها روی دو سیستم است.

Protocol نوع
TCP Connection-oriented
UDP Connectionless

TCP چیست؟

TCP یا Transmission Control Protocol یک پروتکل Connection-oriented است. یعنی قبل از انتقال داده، دو طرف ارتباط TCP را برقرار می‌کنند.

TCP قابلیت‌هایی مانند موارد زیر را فراهم می‌کند:

  • Reliable Delivery
  • Ordered Delivery
  • Acknowledgment
  • Retransmission
  • Flow Control
  • Congestion Control

UDP چیست؟

UDP یا User Datagram Protocol یک پروتکل Connectionless است. برای ارسال داده نیازی به برقراری Connection مانند TCP ندارد.

UDP معمولاً سربار کمتری دارد و برای Applicationهایی مناسب است که Latency پایین یا مدل ارتباطی ساده‌تری می‌خواهند.

💡 UDP به‌خودی‌خود تضمین نمی‌کند Packet حتماً به مقصد برسد یا به همان ترتیب ارسال‌شده دریافت شود.

TCP Three-Way Handshake

TCP برای ایجاد Connection معمولاً از Three-Way Handshake استفاده می‌کند.

TCP Handshake
Client                         Server

   SYN ------------------------>

       <---------------- SYN + ACK

   ACK ------------------------>

        Connection Established

مرحله اول — SYN

Client یک SYN برای شروع Connection ارسال می‌کند.

مرحله دوم — SYN-ACK

Server دریافت SYN را تأیید کرده و SYN-ACK ارسال می‌کند.

مرحله سوم — ACK

Client پاسخ را تأیید می‌کند و Connection آماده انتقال داده می‌شود.

TCP در برابر UDP

ویژگی TCP UDP
Connection دارد ندارد
Reliable Delivery بله خیر
Ordering بله تضمین نمی‌شود
Retransmission بله خیر
Overhead بیشتر کمتر
Latency معمولاً بیشتر معمولاً کمتر

TCP و UDP Ports

Port به Applicationها کمک می‌کند مشخص شود ترافیک مربوط به کدام Service است.

برای مثال:

Common Ports
HTTP   TCP 80
HTTPS  TCP 443
SSH    TCP 22
DNS    UDP 53
DNS    TCP 53

نکته مهم این است که یک شماره Port به‌تنهایی مشخص نمی‌کند TCP است یا UDP؛ پروتکل Transport هم بخشی از شناسایی Endpoint است.

کاربردهای واقعی

Application Protocol
SSH TCP
HTTP/1.1 TCP
HTTPS با HTTP/1.1 یا HTTP/2 TCP
DNS معمولاً UDP؛ در برخی شرایط TCP
DHCP UDP
QUIC UDP

TCP و UDP در DevOps

در DevOps تقریباً هر روز با TCP و UDP سروکار خواهی داشت:

  • Web Server
  • Database Connection
  • SSH
  • DNS
  • Monitoring
  • Load Balancer
  • Docker
  • Kubernetes
  • Cloud Networking

بررسی TCP و UDP در Linux

Terminal
ss -t
ss -u
ss -tuln

گزینه -t برای TCP و گزینه -u برای UDP استفاده می‌شود.

تمرین عملی

🧪 تمرین

روی Ubuntu دستور زیر را اجرا کن:

Terminal
ss -tuln

بررسی کن چه Portهایی Listening هستند و مشخص کن TCP هستند یا UDP.

TCP / UDP Cheat Sheet

Command کاربرد
ss -t TCP Connections
ss -u UDP Sockets
ss -tuln TCP/UDP Listening Ports

چیزی که از این مرحله یاد گرفتم

  • TCP Connection-oriented است.
  • UDP Connectionless است.
  • TCP Delivery و Ordering را مدیریت می‌کند.
  • UDP سربار کمتری دارد و تضمین Delivery ندارد.
  • Portها در Transport Layer نقش مهمی دارند.
