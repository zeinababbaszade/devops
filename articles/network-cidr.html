CIDR چیست؟

CIDR مخفف Classless Inter-Domain Routing است.

CIDR روشی برای نمایش IP Network با استفاده از Prefix Length است.

مثلاً: 

192.168.1.0/24

Prefix Length

عدد بعد از / تعداد بیت‌هایی را نشان می‌دهد که برای Network Portion استفاده شده‌اند.

مثلاً: 

/24

یعنی 24 بیت از 32 بیت IPv4 مربوط به Network Prefix است.

/24 

192.168.1.0/24

Subnet Mask: 

255.255.255.0

تعداد کل Addressها: 

2^(32-24) = 256

و در حالت معمول 254 Host قابل استفاده داریم.

/25

در /25 تعداد بیت‌های Network برابر 25 است. 

2^(32-25) = 128

یعنی هر Subnet دارای 128 Address است و معمولاً 126 Host قابل استفاده دارد.

/26 

2^(32-26) = 64

در /26 معمولاً 62 Host قابل استفاده داریم.

جدول مهم CIDR

CIDR Total IP Usable Host Subnet Mask
/24 256 254 255.255.255.0
/25 128 126 255.255.255.128
/26 64 62 255.255.255.192
/27 32 30 255.255.255.224
/28 16 14 255.255.255.240
/29 8 6 255.255.255.248
/30 4 2 255.255.255.252

CIDR در DevOps

CIDR یکی از مفاهیمی است که در محیط‌های واقعی DevOps دائماً می‌بینی.

برای مثال در Cloud ممکن است یک VPC یا Virtual Network به صورت زیر تعریف شود: 

10.0.0.0/16

و بعد Subnetهای مختلفی داخل آن ساخته شوند: 

10.0.1.0/24
10.0.2.0/24
10.0.3.0/24

در Docker و Kubernetes نیز مفاهیم CIDR و Network Range اهمیت زیادی دارند.

🧪 تمرین

برای Network زیر موارد زیر را محاسبه کن: 
10.10.20.0/27
  • تعداد کل IPها
  • تعداد Hostهای قابل استفاده
  • Subnet Mask
  • Network Address
  • Broadcast Address

چیزی که یاد گرفتم

CIDR روش استاندارد و بسیار رایج برای نمایش Network Prefix است. عدد بعد از Slash مشخص می‌کند چند بیت برای Network استفاده شده است.

مرحله بعدی چیست؟

حالا که مبانی IP و Subnet را بلدیم، می‌توانیم وارد TCP و UDP شویم و بفهمیم ارتباط بین Applicationها واقعاً چگونه برقرار می‌شود.
