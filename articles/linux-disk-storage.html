Linux Disk & Storage

مدیریت دیسک، فضای ذخیره‌سازی، Partition و Mount در Linux

مدیریت Storage یکی از مهارت‌های مهم برای هر Linux Administrator و DevOps Engineer است.

یکی از مشکلات رایج روی Serverها پر شدن فضای دیسک است. اگر فضای دیسک یک سرور به 100 درصد برسد، ممکن است سرویس‌های مختلف دچار مشکل شوند.

بنابراین باید بتوانیم وضعیت Disk، Partition، Filesystem و فضای مصرف‌شده را بررسی کنیم.

دستور df

دستور df برای مشاهده فضای آزاد و مصرف‌شده Filesystemها استفاده می‌شود. 

df -h

گزینه -h خروجی را به صورت Human Readable نمایش می‌دهد.

برای مثال ممکن است خروجی شامل ستون‌های زیر باشد:

  • Filesystem
  • Size
  • Used
  • Avail
  • Use%
  • Mounted on

دستور du

در حالی که df وضعیت Filesystem را نشان می‌دهد، دستور du برای پیدا کردن حجم مصرف‌شده توسط فایل‌ها و Directoryها بسیار کاربردی است. 

du -sh /var/log

برای پیدا کردن حجم Directoryهای داخل مسیر فعلی: 

du -sh *

برای پیدا کردن موارد حجیم‌تر می‌توانیم از: 

du -h --max-depth=1 /var

دستور lsblk

برای مشاهده Diskها و Partitionهای سیستم: 

lsblk

خروجی خواناتر: 

lsblk -f

گزینه -f اطلاعات Filesystem را نیز نمایش می‌دهد.

💡 نکته:

وقتی یک Disk جدید به Server اضافه می‌کنی، یکی از اولین دستورهایی که باید اجرا کنی lsblk است.

Mount چیست؟

در Linux برای استفاده از یک Filesystem باید آن را در یک مسیر مشخص Mount کنیم.

فرض کنیم یک Disk یا Partition داریم: 

/dev/sdb1

ابتدا یک Directory ایجاد می‌کنیم: 

sudo mkdir /data

سپس آن را Mount می‌کنیم: 

sudo mount /dev/sdb1 /data

برای بررسی: 

df -h

فایل /etc/fstab

Mount کردن به روش بالا معمولاً تا زمان Reboot باقی می‌ماند.

برای اینکه یک Filesystem بعد از Boot نیز به صورت خودکار Mount شود، معمولاً از: 

/etc/fstab

استفاده می‌کنیم.

قبل از تغییر fstab باید بسیار دقت کرد، زیرا یک تنظیم اشتباه می‌تواند باعث مشکل در Boot سیستم شود.

Inode چیست؟

در Linux فقط پر شدن فضای Disk مشکل‌ساز نیست. ممکن است Inodeها نیز تمام شوند.

برای بررسی Inode: 

df -i

اگر Inode به 100 درصد برسد، حتی اگر فضای Disk هنوز آزاد باشد، ممکن است نتوانیم فایل جدید ایجاد کنیم.

وقتی Disk پر شد چه کار کنیم؟

فرض کنیم دستور زیر نشان دهد: 

df -h

و Partition مربوط به / تقریباً 100 درصد پر باشد.

اولین مرحله پیدا کردن Directoryهای بزرگ است. 

sudo du -xh --max-depth=1 / | sort -h

سپس Directoryهای بزرگ‌تر را بررسی می‌کنیم.

برای مثال: 

sudo du -xh --max-depth=1 /var | sort -h

یکی از مواردی که باید بررسی شود Logها هستند. 

sudo du -sh /var/log/*
⚠️ هشدار:

هیچ فایل یا Logای را صرفاً برای خالی کردن Disk بدون بررسی حذف نکن. بعضی فایل‌ها برای سرویس‌ها یا بررسی مشکلات سیستم ضروری هستند.

🧪 تمرین عملی

روی Ubuntu خود این دستورات را اجرا کن: 

df -h
df -i
lsblk
lsblk -f
du -sh /var/*
sudo du -xh --max-depth=1 / | sort -h

📌 Cheat Sheet

دستور کاربرد
df -h فضای Disk
df -i وضعیت Inode
du -sh حجم Directory
lsblk مشاهده Diskها
lsblk -f مشاهده Filesystem
mount Mount کردن Filesystem
