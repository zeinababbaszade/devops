Storage در Linux چیست؟

در سرورهای Linux یکی از مشکلات رایج، پر شدن فضای دیسک است. ممکن است Logها، Databaseها، Docker Images یا فایل‌های موقت به مرور زمان فضای زیادی مصرف کنند.

بنابراین در DevOps باید بتوانیم وضعیت Storage را بررسی کنیم و متوجه شویم کدام Partition یا Directory بیشترین فضا را مصرف می‌کند.

💡 وقتی یک سرویس ناگهان با خطای Disk Full مواجه می‌شود، ابزارهایی مثل df و du از اولین ابزارهایی هستند که باید سراغشان برویم.

بررسی فضای دیسک با df

دستور df فضای آزاد و مصرف‌شده File Systemها را نمایش می‌دهد.

Terminal
df

برای نمایش خواناتر حجم‌ها:

Terminal
df -h

در خروجی معمولاً ستون‌هایی مانند Size، Used، Avail و Use% مشاهده می‌کنیم.

بررسی حجم فایل‌ها با du

دستور du برای بررسی مقدار فضای مصرف‌شده توسط فایل‌ها و Directoryها استفاده می‌شود.

Terminal
du -sh /var/log

برای بررسی حجم Directoryهای داخل یک مسیر:

Terminal
du -h --max-depth=1 /var

شناخت Disk و Partition با lsblk

برای مشاهده Diskها و Partitionهای سیستم از lsblk استفاده می‌کنیم.

Terminal
lsblk

برای نمایش اطلاعات بیشتر:

Terminal
lsblk -f

این دستور به ما کمک می‌کند File System و Mount Pointها را بهتر بشناسیم.

Mount چیست؟

در Linux برای استفاده از یک File System معمولاً باید آن را در یک مسیر از سیستم فایل Mount کنیم.

مثلاً یک Disk می‌تواند در مسیر زیر Mount شود:

Example
/data

برای مشاهده Mountهای فعلی:

Terminal
findmnt

فایل fstab

فایل /etc/fstab برای تعریف File Systemهایی استفاده می‌شود که باید هنگام Boot سیستم Mount شوند.

Terminal
cat /etc/fstab
⚠️ تغییر اشتباه در /etc/fstab می‌تواند باعث مشکل در Boot شدن سیستم شود. قبل از تغییر، از فایل Backup بگیر.

Inode چیست؟

هر فایل در Linux علاوه بر اطلاعات مربوط به نام و محتوا، اطلاعات Metadata دارد که در ساختاری به نام inode نگهداری می‌شود.

گاهی فضای Disk هنوز آزاد است اما تعداد Inodeها تمام شده است. برای بررسی آن می‌توان از این دستور استفاده کرد:

Terminal
df -i

تمرین عملی: Disk Lab

🧪 تمرین

ابتدا وضعیت فضای Disk را بررسی کن:

Terminal
df -h

سپس وضعیت Diskها را ببین:

Terminal
lsblk -f

بعد حجم Directoryهای مهم را بررسی کن:

Terminal
sudo du -h --max-depth=1 /var

در نهایت Inodeها را بررسی کن:

Terminal
df -i

Storage Cheat Sheet

Command کاربرد
df -h بررسی فضای File System
du -sh PATH حجم یک Directory
lsblk نمایش Disk و Partition
lsblk -f نمایش File System
findmnt نمایش Mountها
df -i بررسی Inode
cat /etc/fstab مشاهده تنظیمات Mount هنگام Boot

چیزی که از این مرحله یاد گرفتم

  • با df فضای File System را بررسی می‌کنم.
  • با du می‌توانم حجم Directoryها را پیدا کنم.
  • با lsblk Disk و Partitionها را می‌بینم.
  • Mount برای اتصال File System به یک مسیر استفاده می‌شود.
  • فایل /etc/fstab برای Mountهای دائمی مهم است.
  • Inodeها نیز می‌توانند تمام شوند.
