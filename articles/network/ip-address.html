IP چیست؟

IP Address یک آدرس منطقی برای Interface است. Routerها بر اساس Prefix مقصد مسیر را انتخاب می‌کنند.

Network و Host

Prefix مشخص می‌کند چه بخشی Network و چه بخشی Host است؛ این پایه Subnetting است.

IPv4

IPv4 دارای 32 بیت است و معمولاً در چهار Octet ده‌دهی نمایش داده می‌شود.

IPv6

IPv6 دارای 128 بیت است و با گروه‌های Hexadecimal نمایش داده می‌شود.

Special Addresses

127.0.0.1 Loopback است؛ 0.0.0.0 در IPv4 unspecified است؛ ::1 در IPv6 Loopback است.

Linux

ip addr آدرس‌ها و ip route مسیرها را نشان می‌دهد.

🧪 Lab عملی

تمرین مرحله‌ای

در Ubuntu این دستورات را اجرا کنید و برای هر خروجی یک جمله توضیح بنویسید. هدف، فهمیدن رابطه بین تئوری و وضعیت واقعی سیستم است.

Ubuntu
ip addr
ip route
ss -lntup
ping -c 4 1.1.1.1
curl -I https://example.com

اگر دستوری خطا داد، متن خطا را ثبت کنید و مشخص کنید مشکل احتمالاً در کدام بخش است: Interface/IP، Routing، DNS، Transport، TLS یا Application.
