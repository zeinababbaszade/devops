Network، Broadcast و Host چیستند؟

وقتی یک IPv4 Address را همراه با Subnet Mask یا Prefix بررسی می‌کنیم، می‌توانیم بفهمیم این Address متعلق به کدام Network است، Broadcast آن کدام Address است و چه Addressهایی برای Hostها قابل استفاده هستند.

💡 در یک Subnet معمولی IPv4، اولین Address معمولاً Network Address و آخرین Address معمولاً Broadcast Address است و Addressهای بین آن‌ها برای Hostها استفاده می‌شوند.

Network Address چیست؟

Network Address آدرسی است که خود شبکه را مشخص می‌کند و به یک Host اختصاص داده نمی‌شود.

برای مثال در شبکه:

Network
192.168.10.0/24

آدرس 192.168.10.0، Network Address این Subnet است.

Broadcast Address چیست؟

Broadcast Address آخرین Address یک IPv4 Subnet است و برای ارسال ترافیک به تمام Hostهای همان Subnet استفاده می‌شود.

برای:

Network
192.168.10.0/24

Broadcast Address برابر است با:

Broadcast
192.168.10.255

Host Address چیست؟

Host Address به Addressهایی گفته می‌شود که می‌توانند به Interface یک دستگاه مانند Server، PC، Router یا Container اختصاص داده شوند.

در شبکه 192.168.10.0/24 محدوده معمول Hostها:

Host Range
192.168.10.1 - 192.168.10.254
نوع Address
Network 192.168.10.0
First Host 192.168.10.1
Last Host 192.168.10.254
Broadcast 192.168.10.255

مثال عملی

فرض کنیم Server ما این Address را دارد:

Server
192.168.20.45/24

با توجه به /24، سه بخش اول Network هستند. بنابراین:

Network Information
Network   : 192.168.20.0
First Host: 192.168.20.1
Server    : 192.168.20.45
Last Host : 192.168.20.254
Broadcast : 192.168.20.255

نگاه باینری

IPv4 دارای 32 بیت است و در Subnetting این 32 بیت بین بخش Network و Host تقسیم می‌شوند.

برای یک /24:

IPv4 /24
11111111.11111111.11111111.00000000
<--------- Network --------><-Host->

یعنی 24 بیت برای Network و 8 بیت برای Host در نظر گرفته شده است.

بررسی در Linux

در Linux می‌توان Address و Prefix Interfaceها را با دستور ip addr مشاهده کرد.

Terminal
ip addr

برای مشاهده Routeهای سیستم نیز می‌توان از دستور زیر استفاده کرد:

Terminal
ip route

چرا این موضوع برای DevOps مهم است؟

در DevOps دائماً با Network Address و Subnet سروکار داریم.

  • ساخت Network در Cloud

⚠️ اشتباه در محاسبه Network Range می‌تواند باعث اشتباه در Firewall، Routing، Security Group و دسترسی Serverها شود.

Network Address Cheat Sheet

Concept Meaning
Network Address شناسه خود شبکه
Broadcast Address آخرین Address برای Broadcast در IPv4 Subnet
Host Address Address قابل اختصاص به Host
ip addr مشاهده IP و Prefix Interface
ip route مشاهده Routing Table

چیزی که از این مرحله یاد گرفتم

  • Network Address شبکه را مشخص می‌کند.
  • Broadcast Address آخرین Address Subnet است.
  • Addressهای بین Network و Broadcast معمولاً برای Hostها استفاده می‌شوند.
  • Prefix Length تعیین می‌کند چه بخشی از IPv4 مربوط به Network است.
  • تشخیص صحیح این سه مفهوم برای Subnetting بسیار مهم است.
