Linux SSH

اتصال امن به سرورهای لینوکسی و مدیریت Remote Server

وقتی وارد دنیای DevOps و مدیریت سرور می‌شویم، یکی از اولین ابزارهایی که باید یاد بگیریم SSH است.

در محیط واقعی معمولاً سرورها در دیتاسنتر، Cloud یا Virtual Machine قرار دارند و ما مستقیماً به آن‌ها دسترسی فیزیکی نداریم.

SSH به ما اجازه می‌دهد از طریق شبکه به سرور متصل شویم و دستورات لینوکس را روی آن اجرا کنیم.

SSH چیست؟

SSH مخفف Secure Shell است.

SSH یک پروتکل برای برقراری ارتباط امن و رمزنگاری‌شده بین دو سیستم است.

رایج‌ترین استفاده SSH در DevOps، اتصال به Linux Server و مدیریت آن از راه دور است.

💡 نکته:

SSH فقط برای Login کردن نیست. می‌توان با استفاده از آن فایل منتقل کرد، دستورات Remote اجرا کرد و سیستم‌های مختلف را به شکل امن مدیریت کرد.

SSH Client و SSH Server

در یک ارتباط SSH دو طرف وجود دارند.

SSH Client

سیستمی که از آن برای برقراری اتصال استفاده می‌کنیم. مثلاً لپ‌تاپ یا کامپیوتر شخصی ما.

SSH Server

سیستمی که می‌خواهیم به آن متصل شویم. برای مثال یک Ubuntu Server.

اتصال به Linux Server

ساختار اصلی دستور SSH به صورت زیر است: 

ssh username@server-ip

برای مثال: 

ssh admin@192.168.1.100

در این مثال:

  • admin نام کاربر است.
  • 192.168.1.100 آدرس IP سرور است.

پورت SSH

پورت پیش‌فرض SSH معمولاً 22 است. 

ssh -p 22 admin@192.168.1.100

اگر SSH روی پورت دیگری اجرا شود، می‌توان آن را مشخص کرد: 

ssh -p 2222 admin@192.168.1.100

SSH Key چیست؟

یکی از روش‌های رایج احراز هویت در SSH استفاده از Key Pair است.

این Key Pair شامل دو بخش است:

  • Private Key
  • Public Key

Private Key باید روی سیستم خودمان باقی بماند و نباید در اختیار دیگران قرار گیرد.

Public Key را می‌توان روی سرور قرار داد.

⚠️ هشدار امنیتی

Private Key را داخل GitHub، سایت عمومی، Telegram یا هیچ محل عمومی دیگری قرار نده.

ساخت SSH Key 

ssh-keygen -t ed25519

فایل‌های Key معمولاً در مسیر زیر ایجاد می‌شوند: 

~/.ssh/

برای مثال: 

id_ed25519
id_ed25519.pub

کپی Public Key روی Server 

ssh-copy-id admin@192.168.1.100

SSH Config

اگر با چندین Server کار کنیم، نوشتن IP و Username در هر بار اتصال خسته‌کننده می‌شود.

برای این کار می‌توانیم از فایل: 

~/.ssh/config

استفاده کنیم. 

Host myserver
    HostName 192.168.1.100
    User admin
    Port 22

حالا فقط کافی است بنویسیم: 

ssh myserver

انتقال فایل با SCP

SCP برای انتقال فایل بین سیستم‌ها از طریق SSH استفاده می‌شود.

ارسال فایل 

scp backup.tar.gz admin@192.168.1.100:/home/admin/

دریافت فایل 

scp admin@192.168.1.100:/home/admin/backup.tar.gz .

عیب‌یابی SSH

اگر اتصال SSH برقرار نمی‌شود، باید مرحله‌به‌مرحله مشکل را بررسی کنیم.

بررسی شبکه 

ping 192.168.1.100

بررسی پورت 

nc -zv 192.168.1.100 22

SSH Debug 

ssh -v admin@192.168.1.100

برای Debug بیشتر: 

ssh -vvv admin@192.168.1.100

بررسی سرویس SSH 

sudo systemctl status ssh

مشاهده Log 

sudo journalctl -u ssh

نکات امنیتی SSH

  • استفاده از SSH Key
  • استفاده از Password قوی
  • محدود کردن دسترسی شبکه
  • استفاده صحیح از Firewall
  • بررسی Logهای Login
  • جلوگیری از قرار دادن Private Key در Repository عمومی

🧪 تمرین عملی

اگر یک Ubuntu Server در اختیار داری، ابتدا به آن متصل شو: 

ssh username@SERVER_IP

سپس دستورات زیر را اجرا کن: 

whoami
hostname
uptime
df -h
sudo systemctl status ssh

📌 Cheat Sheet

دستور کاربرد
ssh user@host اتصال به سرور
ssh -p 2222 user@host اتصال به پورت مشخص
ssh-keygen -t ed25519 ساخت SSH Key
ssh-copy-id user@host کپی Public Key
ssh -vvv user@host Debug اتصال
scp file user@host:/path انتقال فایل
journalctl -u ssh مشاهده Log
