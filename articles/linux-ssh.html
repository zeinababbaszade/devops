SSH چیست؟

SSH یا Secure Shell یکی از مهم‌ترین ابزارهایی است که در مدیریت سرورها و محیط‌های DevOps استفاده می‌شود. با SSH می‌توانیم از یک سیستم به سیستم دیگری متصل شویم و دستورات Linux را روی سیستم مقصد اجرا کنیم.

فرض کن یک Ubuntu Server در دیتاسنتر داریم و سیستم شخصی ما فقط از طریق شبکه به آن دسترسی دارد. به جای اینکه مستقیماً پشت سرور بنشینیم، می‌توانیم با SSH به آن متصل شویم.

💡 تقریباً هر DevOps Engineer باید بتواند با SSH به سرور Linux متصل شود و Session خود را مدیریت کند.

نصب و بررسی SSH

در Ubuntu معمولاً سمت سرور به بسته‌ای به نام OpenSSH Server نیاز داریم. ابتدا وضعیت سرویس SSH را بررسی می‌کنیم:

Ubuntu Terminal
sudo systemctl status ssh

اگر SSH نصب نشده باشد، می‌توانیم آن را نصب کنیم:

Ubuntu Terminal
sudo apt update
sudo apt install openssh-server

بعد از نصب، سرویس SSH را بررسی می‌کنیم:

Terminal
sudo systemctl enable --now ssh

اتصال به سرور

فرمت اصلی اتصال SSH به شکل زیر است:

Terminal
ssh username@server-ip

برای مثال اگر Username ما zeinab و IP سرور 192.168.1.100 باشد:

Example
ssh zeinab@192.168.1.100

در اولین اتصال ممکن است SSH درباره Fingerprint سرور سؤال کند. پس از تأیید، معمولاً رمز عبور User از ما درخواست می‌شود.

پورت SSH

پورت پیش‌فرض SSH معمولاً 22 است. اگر SSH روی پورت دیگری اجرا شود، باید پورت را هنگام اتصال مشخص کنیم.

Terminal
ssh -p 2222 username@192.168.1.100

برای مشاهده Listening Portها می‌توانیم از ابزارهایی مانند ss استفاده کنیم:

Terminal
sudo ss -tulpn | grep ssh

دستورات مهم SSH

SSH فقط برای برقراری اتصال نیست. چند Option مهم آن را باید بشناسیم.

Command کاربرد
ssh user@host اتصال به سرور
ssh -p 2222 user@host اتصال با پورت مشخص
ssh -v user@host نمایش اطلاعات بیشتر هنگام اتصال
exit خروج از Session

انتقال فایل با SCP

یکی از ابزارهای کاربردی در کنار SSH، دستور scp است. با SCP می‌توانیم فایل‌ها را از یک سیستم به سیستم دیگر منتقل کنیم.

برای ارسال فایل از سیستم خودمان به سرور:

Terminal
scp test.txt username@192.168.1.100:/home/username/

برای دریافت فایل از سرور:

Terminal
scp username@192.168.1.100:/home/username/test.txt .

SSH Key چیست؟

در محیط‌های واقعی DevOps بهتر است برای Authentication از SSH Key استفاده کنیم. در این روش به جای ارسال Password، از یک جفت کلید استفاده می‌شود.

این جفت کلید شامل موارد زیر است:

  • Private Key که باید محرمانه باقی بماند.
  • Public Key که می‌تواند روی سرور قرار بگیرد.

برای ساخت SSH Key:

Terminal
ssh-keygen -t ed25519

برای کپی کردن Public Key روی سرور:

Terminal
ssh-copy-id username@192.168.1.100
⚠️ فایل Private Key را در اختیار دیگران قرار نده و آن را داخل Git Repository عمومی قرار نده.

نکات امنیتی SSH

SSH یک سرویس بسیار مهم است و در سرورهای واقعی باید با دقت پیکربندی شود.

  • از Password قوی استفاده کن.
  • ترجیحاً از SSH Key استفاده کن.
  • دسترسی Root را تا حد امکان محدود کن.
  • پورت SSH را در صورت نیاز تغییر بده، اما آن را جایگزین کنترل‌های امنیتی اصلی ندان.
  • Firewall را به شکل مناسب تنظیم کن.
  • لاگ‌های SSH را بررسی کن.

🧪 تمرین

اگر دو ماشین Ubuntu داری، یکی را به عنوان Client و دیگری را به عنوان Server در نظر بگیر. ابتدا IP سرور را پیدا کن:

Server
ip addr

سپس از Client به Server متصل شو:

Client
ssh username@SERVER_IP

بعد از ورود چند دستور ساده اجرا کن:

SSH Session
whoami
hostname
pwd
ip addr
exit

هدف تمرین این است که چرخه اتصال → اجرای Command → بررسی Server → خروج را تجربه کنی.

SSH Cheat Sheet

Command کاربرد
ssh user@host اتصال به سرور
ssh -p PORT user@host اتصال با پورت مشخص
ssh -v user@host Debug اتصال SSH
scp file user@host:/path ارسال فایل
ssh-keygen ساخت SSH Key
ssh-copy-id کپی Public Key روی سرور
exit خروج از SSH

چیزی که از این مرحله یاد گرفتم

  • SSH ابزار اصلی مدیریت Remote Server است.
  • با SSH می‌توانم به سرور Linux متصل شوم.
  • پورت پیش‌فرض SSH معمولاً 22 است.
  • با SCP می‌توانم فایل منتقل کنم.
  • SSH Key برای Authentication بسیار مهم است.
  • Private Key باید کاملاً محرمانه باقی بماند.
