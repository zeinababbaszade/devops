🌐 IP Address چیست؟

IP Address یا آدرس IP یک آدرس منطقی برای شناسایی یک Interface در شبکه است.

وقتی یک کامپیوتر، سرور، VM یا Container می‌خواهد با سیستم دیگری در شبکه ارتباط برقرار کند، معمولاً از IP Address برای مشخص کردن مقصد استفاده می‌شود.

نکته: MAC Address بیشتر برای ارتباط در یک شبکه محلی استفاده می‌شود، در حالی که IP Address برای آدرس‌دهی منطقی و مسیریابی بین شبکه‌ها استفاده می‌شود.

🔵 IPv4 چیست؟

IPv4 یا Internet Protocol version 4 یکی از اصلی‌ترین نسخه‌های پروتکل IP است.

IPv4 از یک آدرس 32 بیتی استفاده می‌کند.

این 32 بیت معمولاً به چهار بخش 8 بیتی تقسیم می‌شوند. هر بخش عددی بین 0 تا 255 دارد.

IPv4 Example
192.168.1.10

🧩 ساختار IPv4

یک IPv4 از 32 بیت تشکیل شده است:

Binary
11000000.10101000.00000001.00001010

این مقدار به شکل Decimal نمایش داده می‌شود:

Decimal
192.168.1.10

در شبکه، بخشی از IP مربوط به Network و بخشی مربوط به Host است. تعداد بیت‌های هر بخش توسط Prefix یا Subnet Mask مشخص می‌شود.

📦 انواع مهم IPv4

نوع مثال توضیح
Private 192.168.1.10 برای شبکه‌های داخلی
Loopback 127.0.0.1 اشاره به سیستم خودش
Unspecified 0.0.0.0 آدرس نامشخص / همه Interfaceها در برخی کاربردها
Broadcast 192.168.1.255 ارسال به تمام Hostهای Subnet

Private IPv4

سه محدوده اصلی Private IPv4 طبق RFC1918 عبارت‌اند از:

Range CIDR
10.0.0.0 - 10.255.255.255 10.0.0.0/8
172.16.0.0 - 172.31.255.255 172.16.0.0/12
192.168.0.0 - 192.168.255.255 192.168.0.0/16

🟣 IPv6 چیست؟

IPv6 یا Internet Protocol version 6 نسل جدیدتر پروتکل IP است که برای حل مشکل محدودیت آدرس‌های IPv4 طراحی شد.

IPv6 از آدرس 128 بیتی استفاده می‌کند. بنابراین فضای آدرس بسیار بزرگ‌تری نسبت به IPv4 دارد.

IPv6 Example
2001:db8:85a3:0000:0000:8a2e:0370:7334

🧩 ساختار IPv6

یک IPv6 از 128 بیت تشکیل شده که به هشت گروه 16 بیتی تقسیم می‌شود. هر گروه با Hexadecimal نمایش داده می‌شود.

IPv6 Structure
2001 : 0db8 : 85a3 : 0000 : 0000 : 8a2e : 0370 : 7334

کوتاه کردن IPv6

در IPv6 می‌توان صفرهای ابتدایی هر گروه را حذف کرد. همچنین یک رشته متوالی از گروه‌های صفر را می‌توان با :: جایگزین کرد.

IPv6 Compression
2001:0db8:0000:0000:0000:0000:0000:0001

2001:db8::1
توجه: در یک IPv6، علامت :: فقط یک بار می‌تواند برای فشرده‌سازی استفاده شود؛ چون در غیر این صورت مشخص نیست چند گروه صفر حذف شده‌اند.

📦 انواع مهم IPv6

نوع Prefix کاربرد
Global Unicast 2000::/3 آدرس‌های قابل مسیریابی در اینترنت
Link-Local fe80::/10 ارتباط روی Local Link
Unique Local fc00::/7 شبکه‌های خصوصی IPv6
Loopback ::1 خود سیستم
Unspecified :: آدرس نامشخص

⚔️ IPv4 vs IPv6

ویژگی IPv4 IPv6
اندازه آدرس 32 بیت 128 بیت
نمایش Decimal Hexadecimal
مثال 192.168.1.10 2001:db8::10
Broadcast دارد ندارد
ARP استفاده می‌شود استفاده نمی‌شود
Neighbor Discovery خیر بله
فضای آدرس محدودتر بسیار بزرگ

🐧 مشاهده IP در Linux

در Linux مدرن بهترین ابزار برای مشاهده Interfaceها و IPها دستور ip است.

Linux
ip addr

یا:

Linux
ip a

برای مشاهده Route:

Linux
ip route

برای مشاهده IPv6:

Linux
ip -6 addr
ip -6 route

🚀 IPv4 و IPv6 در DevOps

شناخت IPv4 و IPv6 برای DevOps بسیار مهم است. تقریباً در تمام بخش‌های زیر با IP سروکار داریم:

  • Linux Server
  • SSH
  • Docker Networking
  • Kubernetes
  • Load Balancer
  • Reverse Proxy
  • Firewall
  • Cloud Networking
  • Monitoring
  • DNS
مثال: فرض کنید یک Application روی این آدرس اجرا شده باشد:

192.168.10.20:8080

در اینجا:
IP = 192.168.10.20
Port = 8080

🧪 تمرین

تمرین ۱

مشخص کنید آدرس زیر IPv4 است یا IPv6: 

192.168.100.20

تمرین ۲

آدرس زیر چه نوع آدرسی است؟ 

127.0.0.1

تمرین ۳

IPv6 زیر را به شکل کوتاه بنویسید: 

2001:0db8:0000:0000:0000:0000:0000:0001

تمرین ۴

در Ubuntu خود دستور زیر را اجرا کنید و IPv4 و IPv6 Interface اصلی سیستم را پیدا کنید. 

ip addr

📋 Cheat Sheet

دستور کاربرد
ip addr نمایش IP Interfaceها
ip route نمایش Routing Table
ip -6 addr نمایش IPv6
ip -6 route نمایش IPv6 Routes

🎯 چه چیزی یاد گرفتیم؟

  • IP Address چیست.
  • IPv4 از 32 بیت استفاده می‌کند.
  • IPv6 از 128 بیت استفاده می‌کند.
  • ساختار IPv4 و IPv6 را شناختیم.
  • Private IPv4 را شناختیم.
  • Global، Link-Local و Loopback در IPv6 را شناختیم.
  • تفاوت IPv4 و IPv6 را بررسی کردیم.
  • نحوه مشاهده IP در Linux را یاد گرفتیم.
مرحله بعد: حالا که IPv4 و IPv6 را می‌شناسیم، باید یاد بگیریم یک IP چگونه به بخش Network و Host تقسیم می‌شود. این دقیقاً جایی است که Subnet Mask وارد می‌شود.
