Linux Users & Groups

Understanding Linux users, groups, user management and sudo privileges.

Introduction

Linux is designed as a multi-user operating system. Different users can have different permissions and access to system resources.

Understanding users and groups is essential for system administration and DevOps.

In this article we will learn how to inspect users, create users, manage groups and work with sudo.

1. Checking the Current User

The simplest way to find out which user is currently logged in is the whoami command. 

whoami

Another useful command is: 

id

The id command shows information about the current user's UID, GID and groups.

2. Understanding /etc/passwd

Linux stores information about local users in: 

/etc/passwd

We can inspect it with: 

cat /etc/passwd

Each line represents a user account.

You can also search for a specific user: 

grep username /etc/passwd
Security note:

Do not edit /etc/passwd manually unless you fully understand the consequences. Use system management commands instead.

3. Creating a User

The adduser command provides an interactive way to create a new user on Ubuntu. 

sudo adduser devopsuser

Ubuntu will ask for a password and some additional information.

After creating the user, check it with: 

id devopsuser

You can also check its Home directory: 

ls -la /home/devopsuser

4. Switching Users

The su command can be used to switch to another user. 

su - devopsuser

To return to the previous user: 

exit

Another common command is sudo -u, which allows a command to run as another user when permitted.

5. Linux Groups

Groups make it easier to manage permissions for multiple users.

To see the groups of the current user: 

groups

Or: 

id

6. Creating a Group

The groupadd command creates a new group. 

sudo groupadd devops

Check the group: 

getent group devops

7. Adding a User to a Group

We can add a user to a group using: 

sudo usermod -aG devops devopsuser

The important part is: 

-aG

The -a means append, while -G specifies supplementary groups.

Check the user's groups: 

id devopsuser
Important:

After changing a user's group membership, the user may need to start a new login session before the change is reflected in that session.

8. Understanding sudo

Some administrative operations require elevated privileges.

The sudo command allows an authorized user to run a command with elevated privileges. 

sudo apt update

Another example: 

sudo systemctl status ssh

In DevOps, you will frequently encounter sudo when managing servers.

9. Useful User Management Commands

Command Purpose
whoami Show current user
id Show user and group IDs
groups Show user's groups
adduser Create a user
groupadd Create a group
usermod Modify a user
passwd Change a password
su Switch user
sudo Run an authorized command with elevated privileges

10. Practical Lab

Now let's create a small user and group environment.

Step 1 — Create a group

sudo groupadd devops-lab

Step 2 — Create a user

sudo adduser labuser

Step 3 — Check the user

id labuser

Step 4 — Add the user to the group

sudo usermod -aG devops-lab labuser

Step 5 — Check group membership

id labuser

You should see devops-lab among the user's groups.

Step 6 — Switch to the new user

su - labuser

Step 7 — Check the current user

whoami

The result should be: 

labuser

Step 8 — Return to your original user

exit

Step 9 — Clean up the lab

When you finish experimenting, you can remove the test user and group. 

sudo deluser labuser
sudo groupdel devops-lab
Important:

Only run the cleanup commands if labuser and devops-lab were created specifically for this lab.

11. Why Users & Groups Matter in DevOps

User and group management becomes very important when working with Linux servers.

For example, a production server may have:

  • System administrators
  • Developers
  • Deployment users
  • Monitoring services
  • Application users

Giving every account unrestricted access is dangerous. Good system administration follows the principle of least privilege.

Later, when we work with SSH, Docker and CI/CD, these concepts will become even more important.
