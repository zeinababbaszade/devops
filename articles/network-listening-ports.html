Listening Port چیست؟

وقتی یک Service منتظر دریافت Connection روی یک Port باشد، می‌گوییم روی آن Port در حالت Listening قرار دارد.

Example
0.0.0.0:22
0.0.0.0:80

بررسی Listening Portها با ss

Terminal
ss -tuln

برای مشاهده Process مربوط به Socketها:

Terminal
sudo ss -tulnp

پیدا کردن Process

فرض کنیم Port 8080 در حال Listen است:

Terminal
sudo ss -ltnp | grep :8080

ممکن است خروجی شامل نام Process و PID باشد.

استفاده از lsof

دستور lsof می‌تواند فایل‌ها و Socketهای باز را نمایش دهد.

Terminal
sudo lsof -i :8080

برای مشاهده TCP Listening:

Terminal
sudo lsof -iTCP -sTCP:LISTEN -nP

ارتباط با systemd

اگر Process متعلق به یک Service باشد، می‌توان وضعیت Service را با systemctl بررسی کرد.

Terminal
systemctl status ssh

127.0.0.1 در برابر 0.0.0.0

این تفاوت در Troubleshooting بسیار مهم است.

Address مفهوم
127.0.0.1:8080 فقط روی Localhost قابل دسترسی است.
0.0.0.0:8080 روی IPv4 Interfaceهای سیستم Listen می‌کند، مگر Firewall یا تنظیم دیگری مانع شود.

IPv6 Listening

ممکن است یک Service روی IPv6 نیز Listen کند:

Example
[::]:80

Troubleshooting Listening Ports

اگر یک Service از بیرون قابل دسترسی نیست، مراحل زیر را بررسی کن:

  1. آیا Service اجرا است؟
  2. آیا Port Listening است؟
  3. روی چه IP Addressای Listen می‌کند؟
  4. Firewall اجازه دسترسی می‌دهد؟
  5. Routing درست است؟
  6. آیا Client به Host درست وصل می‌شود؟
⚠️ اینکه یک Port روی Server Listening باشد به این معنی نیست که از شبکه یا اینترنت حتماً قابل دسترسی است. Firewall، Routing و Security Group نیز باید اجازه دهند.

تمرین عملی

🧪 Listening Port Lab

روی Ubuntu اجرا کن:

Terminal
sudo ss -tulnp

sudo lsof -i -P -n | grep LISTEN

systemctl --type=service --state=running

حداقل سه Port پیدا کن و مشخص کن هر Port متعلق به کدام Process یا Service است.

Listening Ports Cheat Sheet

Command کاربرد
ss -tuln Listening TCP/UDP
sudo ss -tulnp Listening + Process
sudo lsof -i :8080 Process مربوط به Port
systemctl status service وضعیت Service

چیزی که از این مرحله یاد گرفتم

  • Listening یعنی Service منتظر Connection است.
  • ss ابزار اصلی بررسی Socketها در Linux است.
  • با ss -p می‌توان Process را پیدا کرد.
  • lsof برای پیدا کردن Processهای مرتبط با Port بسیار مفید است.
  • 127.0.0.1 با 0.0.0.0 تفاوت مهمی دارد.
