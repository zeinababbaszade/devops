My first steps learning Linux for DevOps

September 2026 · Linux · DevOps

مقدمه

یکی از اولین مهارت‌هایی که برای ورود به دنیای DevOps باید یاد بگیرم، کار با Linux است.

بیشتر سرورها، ابزارهای DevOps و محیط‌های Container و Cloud بر پایه Linux اجرا می‌شوند. بنابراین قبل از رفتن سراغ Docker، Kubernetes و CI/CD باید با خود Linux راحت باشم.

هدف این مقاله این نیست که Linux را در یک روز یاد بگیرم. هدف این است که قدم‌به‌قدم با Linux کار کنم و چیزهایی را که واقعاً یاد می‌گیرم مستند کنم.

Linux چیست؟

Linux یک خانواده از سیستم‌عامل‌های Unix-like است که در سرورها، کامپیوترها، تجهیزات شبکه، Cloud و بسیاری از زیرساخت‌های نرم‌افزاری استفاده می‌شود.

توزیع‌هایی مثل Ubuntu، Debian، Fedora و Red Hat Enterprise Linux از توزیع‌های معروف Linux هستند.

Terminal چیست؟

در Linux می‌توانیم بسیاری از کارهای مدیریتی را مستقیماً از طریق Terminal انجام دهیم.

به جای اینکه برای هر کار از رابط گرافیکی استفاده کنیم، می‌توانیم با Commandها با سیستم کار کنیم.

اولین دستورها

1. pwd

دستور pwd مسیر فعلی‌ای که در آن قرار داریم را نمایش می‌دهد.

pwd

2. ls

برای مشاهده فایل‌ها و پوشه‌های موجود در مسیر فعلی از ls استفاده می‌کنیم.

ls

برای مشاهده جزئیات بیشتر:

ls -la

3. cd

برای تغییر مسیر از دستور cd استفاده می‌کنیم.

cd /tmp

برای برگشتن به Home:

cd ~

4. whoami

این دستور نام کاربری‌ای که با آن وارد Linux شده‌ایم را نمایش می‌دهد.

whoami

5. clear

برای پاک کردن محتوای Terminal:

clear

ساخت اولین پوشه

با دستور mkdir می‌توانیم یک Directory جدید ایجاد کنیم.

mkdir devops-lab

سپس وارد آن می‌شویم:

cd devops-lab

ساخت اولین فایل

برای ایجاد یک فایل خالی می‌توانیم از touch استفاده کنیم.

touch notes.txt

حالا با ls می‌توانیم فایل را ببینیم:

ls

مشاهده محتوای فایل

دستور cat برای نمایش محتوای فایل استفاده می‌شود.

cat notes.txt

نوشتن داخل فایل

برای یک تست ساده می‌توانیم از echo استفاده کنیم.

echo "My first Linux note" > notes.txt

حالا محتوای فایل را ببینیم:

cat notes.txt

چند دستور مهم دیگر

date

نمایش تاریخ و زمان سیستم.

uname -a

نمایش اطلاعات Kernel و سیستم.

hostname

نمایش نام سیستم.

تمرین عملی من

برای اینکه فقط دستورات را حفظ نکنم، یک آزمایش کوچک انجام می‌دهم.

mkdir ~/devops-lab cd ~/devops-lab mkdir linux mkdir docker touch linux/commands.txt touch linux/notes.txt echo "Linux Learning Journey" > linux/notes.txt ls -la ls -la linux cat linux/notes.txt

چیزی که از این مرحله یاد گرفتم

  • Terminal چیست و چگونه با آن کار کنم.
  • مسیر فعلی را با pwd ببینم.
  • فایل‌ها را با ls مشاهده کنم.
  • بین Directoryها با cd جابه‌جا شوم.
  • Directory جدید با mkdir بسازم.
  • فایل جدید با touch ایجاد کنم.
  • محتوای فایل را با cat ببینم.
  • اطلاعات سیستم را با uname بررسی کنم.

مرحله بعد

در مقاله بعدی سراغ Linux File System می‌روم و با مسیرهایی مثل /، /home، /etc، /var و /tmp آشنا می‌شوم.
