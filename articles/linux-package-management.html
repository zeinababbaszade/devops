Package Management چیست؟

نرم‌افزارهای Linux معمولاً به شکل Package نصب و مدیریت می‌شوند. در Ubuntu ابزار اصلی برای مدیریت Packageهای مخازن APT است.

💡 در کار DevOps مرتباً لازم است ابزارهایی مثل Git، curl، Docker، ابزارهای مانیتورینگ یا Utilityهای سیستم را نصب و به‌روزرسانی کنیم؛ بنابراین آشنایی با Package Management ضروری است.

APT چیست؟

APT مجموعه‌ای از ابزارها برای کار با Packageهای Debian و Ubuntu است. معمولاً با apt می‌توانیم اطلاعات مخازن را به‌روزرسانی و Packageها را نصب یا حذف کنیم.

Terminal
apt --version

apt update

دستور apt update فهرست اطلاعات Packageها را از مخازن دریافت می‌کند. این دستور به‌تنهایی Packageهای نصب‌شده را Upgrade نمی‌کند.

Terminal
sudo apt update

apt upgrade

بعد از به‌روزرسانی اطلاعات مخازن، می‌توان Packageهای نصب‌شده را Upgrade کرد.

Terminal
sudo apt upgrade

نصب Package

برای نصب یک Package از apt install استفاده می‌کنیم.

Terminal
sudo apt install tree

بعد می‌توانیم بررسی کنیم که ابزار نصب شده است:

Terminal
tree --version

جست‌وجوی Package

برای جست‌وجوی Packageها می‌توان از apt search استفاده کرد.

Terminal
apt search htop

دیدن اطلاعات Package

برای دیدن اطلاعات یک Package:

Terminal
apt show htop

حذف Package

برای حذف یک Package:

Terminal
sudo apt remove tree

در صورت نیاز به حذف Package و Configurationهای مربوط به آن می‌توان از purge استفاده کرد؛ استفاده از آن باید آگاهانه باشد.

Terminal
sudo apt purge tree

پاک‌سازی Packageهای اضافی

گاهی Packageهایی به عنوان Dependency نصب شده‌اند و بعداً دیگر مورد نیاز نیستند. autoremove برای پاک‌سازی برخی از این موارد استفاده می‌شود.

Terminal
sudo apt autoremove

تمرین عملی: Package Lab

🧪 تمرین

Ubuntu Terminal
sudo apt update
apt search tree
sudo apt install tree
tree --version
apt show tree
sudo apt remove tree

در این تمرین عمداً یک Package کوچک و کم‌خطر را انتخاب کردیم تا چرخه Search → Install → Verify → Remove را تمرین کنیم.

چرا Package Management در DevOps مهم است؟

در محیط‌های واقعی، نصب دستی و بدون کنترل نرم‌افزارها می‌تواند باعث تفاوت بین سرورها شود. در ادامه مسیر، همین مفهوم به Automation و Infrastructure as Code وصل می‌شود؛ یعنی بتوانیم نصب و Configuration را قابل تکرار کنیم.

Commandکاربرد

چیزی که از این مرحله یاد گرفتم

  • APT ابزار مهم مدیریت Package در Ubuntu است.
  • apt update اطلاعات مخازن را تازه می‌کند.
  • apt upgrade Packageهای نصب‌شده را به‌روزرسانی می‌کند.
  • می‌توانم Package را Search، Install، Verify و Remove کنم.
  • Package Management پایه‌ای برای Automation و مدیریت قابل‌تکرار سیستم است.
