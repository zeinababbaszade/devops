Subnetting چیست؟

Subnetting یعنی تقسیم یک Network بزرگ‌تر به چند Network کوچک‌تر.

این کار باعث می‌شود Address Space بهتر مدیریت شود و بتوانیم Network را منطقی‌تر تقسیم کنیم.

چرا Subnetting مهم است؟

در یک سازمان ممکن است Networkهای مختلفی برای Server، User، Management و Monitoring داشته باشیم.

Example 
Network
│
├── Servers
├── Users
├── Management
└── Monitoring

Subnet Mask

Subnet Mask مشخص می‌کند چند بیت برای Network و چند بیت برای Host استفاده می‌شود.

مثلاً:

Example 
255.255.255.0

این Mask معادل /24 است.

Network Address

Network Address اولین Address یک Subnet است و برای شناسایی خود شبکه استفاده می‌شود.

برای:

Example 
192.168.1.0/24

Network Address برابر: 

192.168.1.0

Broadcast Address

آخرین Address در Subnet معمولاً Broadcast Address است.

در: 192.168.1.0/24

Broadcast: 

192.168.1.255

Hostها

در یک /24 تعداد کل Addressها برابر 256 است.

در حالت معمول دو Address برای Network و Broadcast کنار گذاشته می‌شوند. 

256 total
- 1 network
- 1 broadcast
= 254 usable hosts

مثال عملی

فرض کن Network زیر را داریم: 

192.168.10.0/24

و می‌خواهیم آن را به دو Subnet تقسیم کنیم.

با استفاده از /25: 

192.168.10.0/25
192.168.10.128/25
Subnet Network Broadcast Usable
1 192.168.10.0 192.168.10.127 126
2 192.168.10.128 192.168.10.255 126
💡 نکته: Subnetting یکی از مهم‌ترین مباحث Networking برای DevOps است، چون در Cloud، Kubernetes، Docker و دیتاسنترها دائماً با Subnet سروکار داری.

🧪 تمرین

Network زیر را بررسی کن: 
192.168.20.0/26

موارد زیر را پیدا کن:

  • Network Address
  • Broadcast Address
  • تعداد Hostهای قابل استفاده
  • اولین Host
  • آخرین Host

چیزی که یاد گرفتم

Subnetting یعنی تقسیم Network به Subnetهای کوچک‌تر. برای انجام این کار باید بتوانیم Subnet Mask، Network Address، Broadcast و Host Range را محاسبه کنیم.

مرحله بعدی چیست؟

در مقاله بعدی مفهوم CIDR را یاد می‌گیریم؛ روشی که امروزه تقریباً همه‌جا برای نمایش Network Prefix استفاده می‌شود.
