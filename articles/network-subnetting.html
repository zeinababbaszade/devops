Subnetting چیست؟

Subnetting فرآیند تقسیم یک Network بزرگ به Networkهای کوچک‌تر است.

این کار به مدیریت بهتر IPها، جداسازی شبکه‌ها و کنترل Traffic کمک می‌کند.

چرا Subnetting؟

  • استفاده بهتر از IP Addressها
  • تقسیم شبکه‌های بزرگ
  • ایجاد Segmentation
  • بهبود مدیریت شبکه
  • کمک به طراحی Infrastructure

Subnet Mask

Subnet Mask مشخص می‌کند چه بخش‌هایی از IP مربوط به Network و چه بخش‌هایی مربوط به Host هستند.

Example
IP:          192.168.1.10
Subnet Mask: 255.255.255.0
CIDR:        /24

مثال ساده /24

شبکه:

Network
192.168.1.0/24

این Network دارای 256 Address است. اما Network Address و Broadcast Address معمولاً برای Hostهای عادی قابل استفاده نیستند. بنابراین 254 Host Address قابل استفاده خواهیم داشت.

تقسیم /24 به /26

اگر Network 192.168.1.0/24 را به /26 تقسیم کنیم، چهار Subnet خواهیم داشت:

SubnetNetworkBroadcast
1192.168.1.0/26192.168.1.63
2192.168.1.64/26192.168.1.127
3192.168.1.128/26192.168.1.191
4192.168.1.192/26192.168.1.255

محاسبه تعداد Host

در IPv4 تعداد Addressهای یک Prefix برابر است با:

Formula
2^(32 - prefix)

برای /26:

Example
2^(32-26) = 64

در حالت معمول 2 Address برای Network و Broadcast رزرو می‌شوند؛ بنابراین 62 Host Address قابل استفاده داریم.

Broadcast Address

Broadcast Address آخرین Address هر Subnet است. برای مثال در:

Example
192.168.1.64/26

Network Address برابر 192.168.1.64 و Broadcast برابر 192.168.1.127 است. Hostهای قابل استفاده بین این دو قرار دارند.

Subnetting در DevOps

Subnetting در طراحی Infrastructure اهمیت زیادی دارد. مثلاً می‌توان Database، Application و Monitoring را در Subnetهای جداگانه قرار داد.

Example Architecture
VPC
 |
 +-- Public Subnet
 |      |
 |      +-- Load Balancer
 |
 +-- Private App Subnet
 |      |
 |      +-- Application Servers
 |
 +-- Private DB Subnet
        |
        +-- Database

چیزی که یاد گرفتم

  • Subnetting برای تقسیم Network استفاده می‌شود.
  • Subnet Mask مرز Network و Host را مشخص می‌کند.
  • /24 شامل 256 Address است.
  • /26 شامل 64 Address است.
  • Network و Broadcast معمولاً قابل استفاده برای Host نیستند.

مرحله بعدی چیست؟

📐 CIDR

در مقاله بعدی CIDR را دقیق‌تر بررسی می‌کنیم و یاد می‌گیریم Prefixهایی مثل /24، /16 و /30 دقیقاً چه معنایی دارند.
