Service چیست؟

در Linux بسیاری از برنامه‌ها به شکل Service اجرا می‌شوند؛ یعنی برنامه‌ای که معمولاً در پس‌زمینه کار می‌کند و برای سیستم یا کاربران یک وظیفه مشخص انجام می‌دهد. Web Server، SSH و Database نمونه‌هایی از سرویس‌ها هستند.

💡 در Ubuntu جدید، systemd یکی از اجزای اصلی مدیریت سرویس‌ها و فرآیندهای سیستم است و ابزار systemctl رابط اصلی ما برای کار با آن است.

systemctl چیست؟

با systemctl می‌توانیم وضعیت Serviceها را ببینیم و عملیات‌هایی مثل Start، Stop، Restart و Enable را انجام دهیم.

Terminal
systemctl status ssh

اگر SSH روی سیستم نصب نباشد، می‌توانی یک سرویس موجود دیگر را بررسی کنی.

Terminal
systemctl list-units --type=service

بررسی وضعیت Service

یکی از مهم‌ترین دستورها در Troubleshooting همین status است.

Terminal
systemctl status ssh

در خروجی معمولاً می‌توانیم وضعیت سرویس، زمان اجرا و بخشی از Logهای مرتبط را ببینیم.

Start و Stop

برای روشن کردن یک Service:

Terminal
sudo systemctl start ssh

برای متوقف کردن آن:

Terminal
sudo systemctl stop ssh
⚠️ روی یک سرور واقعی، قبل از Stop کردن سرویس‌هایی مثل SSH مطمئن شو دسترسی جایگزین داری؛ چون ممکن است اتصال مدیریتی خودت را از دست بدهی.

Restart و Reload

وقتی تنظیمات یک سرویس تغییر کرده باشد، گاهی نیاز به Restart یا Reload داریم.

Terminal
sudo systemctl restart ssh

در بعضی سرویس‌ها reload اجازه می‌دهد Configuration بدون توقف کامل سرویس دوباره خوانده شود؛ پشتیبانی از آن به خود Service بستگی دارد.

Terminal
sudo systemctl reload ssh

Enable و Disable

start سرویس را همین الان اجرا می‌کند؛ اما برای اجرای خودکار بعد از Boot معمولاً از enable استفاده می‌کنیم.

Terminal
sudo systemctl enable ssh

برای لغو اجرای خودکار:

Terminal
sudo systemctl disable ssh

بررسی Enable بودن

Terminal
systemctl is-enabled ssh

بررسی Logهای Service

برای دیدن Logهای مربوط به systemd می‌توان از journalctl استفاده کرد.

Terminal
journalctl -u ssh

برای دیدن Logهای جدیدتر:

Terminal
journalctl -u ssh -n 50
💡 در Troubleshooting، ترکیب systemctl status و journalctl یکی از مسیرهای مهم پیدا کردن علت مشکل یک Service است.

تمرین عملی: Service Lab

🧪 تمرین

Ubuntu Terminal
systemctl status ssh
systemctl is-enabled ssh
systemctl list-units --type=service --state=running
journalctl -u ssh -n 20

اگر SSH روی سیستم تو وجود ندارد، به جای آن نام یکی از Serviceهای موجود را از خروجی systemctl list-units --type=service انتخاب کن.

systemd Cheat Sheet

Commandکاربرد
systemctl status serviceمشاهده وضعیت Service
systemctl start serviceاجرای Service
systemctl stop serviceتوقف Service
systemctl restart serviceRestart Service
systemctl reload serviceReload تنظیمات در صورت پشتیبانی
systemctl enable serviceاجرای خودکار بعد از Boot
systemctl disable serviceلغو اجرای خودکار
journalctl -u serviceمشاهده Logهای Service

چیزی که از این مرحله یاد گرفتم

  • Serviceها برنامه‌هایی هستند که برای انجام وظایف مشخص سیستم اجرا می‌شوند.
  • systemctl ابزار اصلی مدیریت Serviceهاست.
  • تفاوت Start با Enable را می‌دانم.
  • با status وضعیت Service را بررسی می‌کنم.
  • با journalctl می‌توانم Logهای Service را بررسی کنم.
