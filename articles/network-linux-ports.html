Port چیست؟

یک IP Address مشخص می‌کند ارتباط به کدام Host می‌رود، اما Port کمک می‌کند مشخص شود ارتباط برای کدام Application یا Service است.

Example
192.168.1.10:22
192.168.1.10:80
192.168.1.10:443

در این مثال IP یکسان است اما Portها متفاوت هستند.

Socket چیست؟

Socket یک Endpoint ارتباطی است که معمولاً با ترکیبی از IP، Port و Transport Protocol شناخته می‌شود.

Example
TCP
192.168.1.10:443

Port Range

شماره Port در TCP و UDP از 0 تا 65535 است.

Range نام
0-1023 Well-known Ports
1024-49151 Registered Ports
49152-65535 Dynamic / Private Ports

Portهای معروف

Service Port Protocol
SSH 22 TCP
HTTP 80 TCP
HTTPS 443 TCP
DNS 53 UDP/TCP
SMTP 25 TCP
PostgreSQL 5432 TCP
MySQL 3306 TCP

Service و Port

یک Service مانند SSH Server یا Web Server معمولاً روی یک یا چند Port مشخص Listen می‌کند.

مثلاً SSH Server معمولاً روی Port 22 گوش می‌دهد:

Linux
ss -ltnp | grep :22

Port در Linux

برای مشاهده Listening Portها یکی از مهم‌ترین ابزارها در Linux دستور ss است.

Terminal
ss -tuln

تست Port

برای تست اینکه یک Port از یک سیستم قابل دسترسی است می‌توان از nc استفاده کرد.

Terminal
nc -vz 192.168.1.10 22
💡 موفق بودن TCP Connection به یک Port نشان می‌دهد مسیر شبکه و Listener تا آن نقطه قابل دسترسی هستند؛ اما لزوماً به معنی سالم بودن خود Application نیست.

چرا Portها برای DevOps مهم هستند؟

  • SSH Server
  • Web Server
  • Database
  • Docker
  • Kubernetes
  • Monitoring
  • Firewall
  • Load Balancer

Linux Ports Cheat Sheet

Command کاربرد
ss -tuln نمایش Listening TCP/UDP
ss -ltnp TCP Listening همراه Process
nc -vz host port تست TCP Port

چیزی که از این مرحله یاد گرفتم

  • IP Host را مشخص می‌کند و Port Service را مشخص می‌کند.
  • TCP و UDP هرکدام Port Space جداگانه دارند.
  • Port عددی بین 0 تا 65535 است.
  • Serviceها روی Portهای مشخص Listen می‌کنند.
  • ابزار ss یکی از مهم‌ترین ابزارهای بررسی Port در Linux است.
