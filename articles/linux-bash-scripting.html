Bash چیست؟

Bash یکی از Shellهای معروف در Linux است. Shell محیطی است که به ما اجازه می‌دهد Commandهای سیستم را اجرا کنیم و با سیستم‌عامل تعامل داشته باشیم.

وقتی چند Command را پشت سر هم اجرا می‌کنیم، می‌توانیم آن‌ها را داخل یک فایل قرار دهیم و یک Script بسازیم.

💡 Bash Scripting یکی از اولین قدم‌ها برای ورود به Automation در DevOps است.

اولین Bash Script

یک فایل با پسوند .sh ایجاد کن:

Terminal
nano hello.sh

داخل فایل بنویس:

hello.sh
#!/bin/bash

echo "Hello DevOps"

حالا فایل را قابل اجرا کن:

Terminal
chmod +x hello.sh

و آن را اجرا کن:

Terminal
./hello.sh

Variableها

Variable برای ذخیره مقدار استفاده می‌شود.

Bash
#!/bin/bash

name="Zeinab"

echo "Hello $name"
⚠️ در Bash هنگام Assignment نباید قبل یا بعد از = فاصله قرار بگیرد.

گرفتن Input

با read می‌توانیم از کاربر Input بگیریم.

Bash
#!/bin/bash

read -p "Enter your name: " name

echo "Hello $name"

شرط‌ها

برای تصمیم‌گیری در Script از شرط if استفاده می‌کنیم.

Bash
#!/bin/bash

read -p "Enter a number: " number

if [ "$number" -gt 10 ]; then
    echo "Number is greater than 10"
else
    echo "Number is 10 or less"
fi

در Bash عملگرهای مختلفی برای مقایسه وجود دارند.

Operator کاربرد
-eq برابر
-ne نابرابر
-gt بزرگ‌تر
-lt کوچک‌تر
-ge بزرگ‌تر یا مساوی
-le کوچک‌تر یا مساوی

Loopها

وقتی لازم است یک عملیات چند بار تکرار شود، از Loop استفاده می‌کنیم.

یک نمونه ساده از for:

Bash
#!/bin/bash

for i in 1 2 3 4 5
do
    echo "Number: $i"
done

نمونه‌ای که فایل‌ها را بررسی می‌کند:

Bash
#!/bin/bash

for file in *.log
do
    echo "Log file: $file"
done

Functionها

برای جلوگیری از تکرار Code می‌توانیم Function تعریف کنیم.

Bash
#!/bin/bash

show_info() {
    echo "Linux DevOps Lab"
    hostname
    uptime
}

show_info

Automation ساده

حالا می‌توانیم مفاهیمی که یاد گرفتیم را کنار هم قرار دهیم. مثلاً Scriptی بسازیم که وضعیت Disk و Memory را نمایش دهد.

system-info.sh
#!/bin/bash

echo "===== SYSTEM INFORMATION ====="

echo ""
echo "Hostname:"
hostname

echo ""
echo "Uptime:"
uptime

echo ""
echo "Disk Usage:"
df -h /

echo ""
echo "Memory:"
free -h

echo ""
echo "===== END ====="

این مثال ساده است، اما دقیقاً همان ایده‌ای را نشان می‌دهد که بعداً در Automationهای بزرگ‌تر استفاده می‌کنیم: اجرای چند عملیات به صورت خودکار و تکرارپذیر.

تمرین عملی: Bash Automation Lab

🧪 تمرین

یک Script به نام system-check.sh ایجاد کن:

Terminal
nano system-check.sh

داخل آن Scriptی بنویس که موارد زیر را نمایش دهد:

  • Hostname
  • Current User
  • Uptime
  • Disk Usage
  • Memory Usage

برای مثال:

system-check.sh
#!/bin/bash

echo "===== SYSTEM CHECK ====="

echo "User:"
whoami

echo "Hostname:"
hostname

echo "Uptime:"
uptime

echo "Disk:"
df -h /

echo "Memory:"
free -h

echo "===== DONE ====="

بعد Script را اجرا کن:

Terminal
chmod +x system-check.sh
./system-check.sh

Bash Cheat Sheet

Command / Syntax کاربرد
#!/bin/bash مشخص کردن Interpreter
echo نمایش متن
read گرفتن Input
if شرط
for Loop
function() ساخت Function
chmod +x قابل اجرا کردن Script
./script.sh اجرای Script

چیزی که از این مرحله یاد گرفتم

  • Bash برای اجرای Commandها و Automation بسیار کاربردی است.
  • می‌توانم Commandها را داخل Script قرار دهم.
  • با Variable می‌توانم اطلاعات را ذخیره کنم.
  • با if تصمیم‌گیری کنم.
  • با Loop عملیات تکراری را خودکار کنم.
  • با Function کدها را مرتب‌تر و قابل استفاده مجدد کنم.
  • با Bash می‌توانم Automationهای ساده سیستم را شروع کنم.
