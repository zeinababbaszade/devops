Bash چیست؟

Bash یکی از Shellهای معروف در سیستم‌های Linux و Unix است.

Shell به ما اجازه می‌دهد با سیستم‌عامل از طریق Command Line تعامل داشته باشیم.

اما Bash فقط برای اجرای دستی Commandها نیست. می‌توانیم مجموعه‌ای از دستورات را داخل یک فایل قرار دهیم و آن را به صورت خودکار اجرا کنیم.

به این فایل‌ها معمولاً Bash Script گفته می‌شود.

اولین Bash Script

یک فایل ایجاد کن: 

nano hello.sh

داخل آن بنویس: 

#!/bin/bash

echo "Hello DevOps"

سپس Permission اجرا بده: 

chmod +x hello.sh

و اجرا کن: 

./hello.sh
💡 نکته:

خط اول Script یعنی #!/bin/bash مشخص می‌کند Script با Bash اجرا شود.

Variables

برای ذخیره اطلاعات می‌توانیم از Variable استفاده کنیم. 

name="Zeinab"

برای استفاده: 

echo "$name"

یک مثال دیگر: 

server="production"

echo "Server: $server"

Script Arguments

می‌توانیم هنگام اجرای Script به آن Argument بدهیم. 

./script.sh server01

مقدار اولین Argument در: 

$1

قرار می‌گیرد.

مثال: 

#!/bin/bash

echo "Server: $1"

شرط‌ها در Bash

برای تصمیم‌گیری می‌توانیم از if استفاده کنیم. 

#!/bin/bash

if [ "$1" = "production" ]; then
    echo "Production server"
else
    echo "Other environment"
fi

بررسی وجود فایل 

if [ -f "/etc/hosts" ]; then
    echo "File exists"
fi

بررسی Directory 

if [ -d "/var/log" ]; then
    echo "Directory exists"
fi

Loopها

Loop زمانی کاربرد دارد که بخواهیم یک کار را چند بار انجام دهیم.

For Loop 

for server in server1 server2 server3
do
    echo "Checking $server"
done

مثال کاربردی 

for file in /var/log/*.log
do
    echo "$file"
done

Functionها

برای جلوگیری از تکرار کد می‌توانیم Function ایجاد کنیم. 

check_disk() {
    df -h
}

check_disk

Exit Code

بسیاری از دستورات Linux یک Exit Code برمی‌گردانند.

معمولاً: 

0

به معنی موفقیت است.

برای مشاهده Exit Code آخرین دستور: 

echo $?

مثال 

ls /tmp

echo $?

Bash در Automation

یکی از دلایل اهمیت Bash در DevOps این است که می‌توان بسیاری از کارهای تکراری را Automate کرد.

برای مثال:

  • Backup گرفتن
  • بررسی Disk
  • بررسی Service
  • پاک‌سازی فایل‌های قدیمی
  • بررسی وضعیت Server
  • اجرای چند Command پشت سر هم

یک Script ساده برای بررسی Server 

#!/bin/bash

echo "===== Server Status ====="

echo "Hostname:"
hostname

echo ""

echo "Uptime:"
uptime

echo ""

echo "Disk:"
df -h

echo ""

echo "Memory:"
free -h

echo ""

echo "Load:"
cat /proc/loadavg

چنین Script ساده‌ای می‌تواند یک نقطه شروع خوب برای یادگیری Automation باشد.

🧪 تمرین عملی

یک فایل بساز: 

nano server-check.sh

داخل آن یک Script بنویس که موارد زیر را نمایش دهد:

  • Hostname
  • Uptime
  • Disk Usage
  • Memory Usage
  • IP Address

سپس: 

chmod +x server-check.sh

و: 

./server-check.sh

📌 Cheat Sheet

Syntax کاربرد
#!/bin/bash مشخص کردن Bash
echo چاپ خروجی
$1 اولین Argument
if شرط
for Loop
function ساخت Function
$? Exit Code
chmod +x script.sh قابل اجرا کردن Script
