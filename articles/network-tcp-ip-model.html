TCP/IP چیست؟

TCP/IP مجموعه‌ای از Protocolهاست که بخش بزرگی از شبکه‌های امروزی، مخصوصاً اینترنت، بر اساس آن‌ها کار می‌کنند.

در مسیر DevOps، تقریباً دائماً با TCP/IP سروکار خواهیم داشت؛ از SSH و HTTP گرفته تا Docker، Kubernetes، Monitoring و Cloud.

💡 OSI بیشتر یک مدل آموزشی و مفهومی است، اما TCP/IP مستقیماً با Protocolهای واقعی شبکه‌ای که در سیستم‌ها استفاده می‌کنیم ارتباط دارد.

Application Layer

این لایه شامل Protocolهایی است که Applicationها مستقیماً از آن‌ها استفاده می‌کنند.

  • HTTP / HTTPS
  • DNS
  • SSH
  • SMTP
  • FTP

Transport Layer

Transport Layer مسئول ارتباط End-to-End بین Applicationهاست. دو Protocol اصلی این لایه TCP و UDP هستند.

Port نیز در این لایه اهمیت زیادی دارد. مثلاً SSH معمولاً روی Port 22 و HTTPS روی Port 443 کار می‌کند.

Internet Layer

این لایه مسئول Addressing و Routing است. IP Protocol اصلی این بخش است و Routerها Packetها را بین شبکه‌ها منتقل می‌کنند.

ICMP نیز برای پیام‌های کنترلی و Diagnostic مانند ping استفاده می‌شود.

Network Access Layer

این بخش به انتقال داده در شبکه محلی و ارتباط با Medium فیزیکی مربوط است. Ethernet و MAC Address از مفاهیم مهم آن هستند.

Encapsulation چیست؟

وقتی یک Application داده‌ای را ارسال می‌کند، داده در مسیر عبور از لایه‌های مختلف Headerهای مختلفی دریافت می‌کند. به این فرآیند Encapsulation گفته می‌شود.

برای مثال یک درخواست HTTP در نهایت می‌تواند در TCP Segment، سپس IP Packet و بعد Ethernet Frame قرار بگیرد.

Ubuntu Terminal
curl https://example.com

ss -tn

ip route

ip addr

چیزی که از این مرحله یاد گرفتم

  • TCP/IP اساس ارتباطات شبکه مدرن است.
  • TCP و UDP در Transport Layer قرار دارند.
  • IP و Routing در Internet Layer هستند.
  • HTTP و DNS در Application Layer قرار می‌گیرند.
  • Encapsulation توضیح می‌دهد داده چگونه در لایه‌های مختلف بسته‌بندی می‌شود.
