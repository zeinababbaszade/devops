TCP/IP چیست؟

TCP/IP مجموعه‌ای از Protocolها و مفاهیمی است که ارتباطات شبکه و اینترنت بر اساس آن ساخته شده است.

برخلاف OSI که بیشتر یک مدل مفهومی است، TCP/IP به Protocol Suite واقعی مورد استفاده در شبکه‌های امروزی اشاره می‌کند.

چهار لایه TCP/IP

TCP/IP نمونه
Application HTTP, DNS, SSH
Transport TCP, UDP
Internet IP, ICMP
Network Access Ethernet, Wi-Fi

Application Layer

Application Layer شامل Protocolهایی است که Applicationها مستقیماً با آن‌ها کار می‌کنند.

Examples 
HTTP
HTTPS
DNS
SSH
SMTP
FTP

Transport Layer

در این لایه دو Protocol مهم TCP و UDP قرار دارند.

TCP

TCP قابل اعتماد، Connection-oriented و دارای مکانیزم‌هایی برای Ordering و Retransmission است.

UDP

UDP بدون ایجاد Connection و با Overhead کمتر کار می‌کند.

Internet Layer

وظیفه اصلی این لایه Addressing و Routing Packetها است. IP مهم‌ترین Protocol این لایه است.

ICMP نیز برای پیام‌های کنترلی و ابزارهایی مانند ping اهمیت دارد.

Network Access Layer

این لایه مسئول ارتباط با شبکه محلی و انتقال Frameها روی Ethernet یا Wi-Fi است.

TCP/IP در Linux

Linux ابزارهای بسیار خوبی برای مشاهده وضعیت TCP/IP دارد.

Terminal 
ip addr
ip route
ss -tuln
ping -c 4 8.8.8.8

مثال واقعی

وقتی دستور زیر را اجرا می‌کنیم:

Terminal 
curl https://example.com

چند لایه درگیر می‌شوند:

Flow 
curl
 ↓
HTTPS
 ↓
TCP
 ↓
IP
 ↓
Ethernet
 ↓
Network

🧪 تمرین عملی

این دستورات را اجرا کن و مشخص کن هرکدام به کدام لایه مربوط هستند:
Linux 
ip addr
ip route
ss -tuln
ping -c 4 8.8.8.8
curl -I https://example.com

چیزی که یاد گرفتم

TCP/IP مدل عملی‌تر و نزدیک‌تر به شبکه‌های واقعی است. برای DevOps باید بتوانم یک ارتباط را از Application تا Network دنبال کنم.
