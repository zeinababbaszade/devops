ARP چیست؟

ARP مخفف Address Resolution Protocol است.

وظیفه ARP پیدا کردن MAC Address مربوط به یک IPv4 Address در شبکه محلی است.

ARP چه مشکلی را حل می‌کند؟

فرض کن Server A آدرس زیر را دارد:

Network
IP: 192.168.1.10
MAC: AA:AA:AA:AA:AA:AA

و می‌خواهد برای 192.168.1.20 Packet ارسال کند.

IP مقصد را می‌داند، اما برای ارسال Frame در شبکه Ethernet به MAC مقصد نیاز دارد.

ARP این ارتباط را پیدا می‌کند.

فرآیند ARP

ARP Flow
Who has 192.168.1.20?
        ↓
Broadcast
        ↓
192.168.1.20 replies:
I am AA:BB:CC:DD:EE:FF
        ↓
Store in ARP Table
        ↓
Send Ethernet Frame

ARP Table

سیستم عامل نتیجه ARP را برای مدتی Cache می‌کند. این اطلاعات در Linux در Neighbor Table قابل مشاهده است.

💡 نگه‌داشتن نتیجه در Cache باعث می‌شود سیستم برای هر Packet مجبور نباشد دوباره یک Broadcast جدید بفرستد و ارتباط سریع‌تر برقرار شود.

ARP در Linux

Terminal
ip neigh

ممکن است خروجی شبیه این باشد:

Output
192.168.1.1 dev ens160 lladdr 00:11:22:33:44:55 REACHABLE

ARP و Default Gateway

اگر مقصد خارج از شبکه محلی باشد، سیستم معمولاً Frame را به MAC Address مربوط به Default Gateway ارسال می‌کند.

Flow
Application
     ↓
Destination IP
     ↓
Routing Table
     ↓
Default Gateway
     ↓
ARP → Gateway MAC
     ↓
Ethernet Frame

Troubleshooting با ARP

اگر Host در شبکه محلی قابل دسترسی نیست، می‌توانیم Neighbor Table را بررسی کنیم.

Terminal
ip neigh
ip route
⚠️ نکته امنیتی: ARP در IPv4 ذاتاً مکانیزم Authentication قوی ندارد و حملاتی مانند ARP Spoofing می‌توانند از ضعف‌های آن سوءاستفاده کنند.

تمرین عملی: ARP Lab

🧪 تمرین

اول Gateway سیستم را پیدا کن:

Terminal
ip route

سپس Neighbor Table را بررسی کن:

Terminal
ip neigh

MAC مربوط به Gateway را پیدا کن و آن را با خروجی ip route مقایسه کن.

ARP Cheat Sheet

Commandکاربرد
ip neighنمایش ARP / Neighbor Table
ip routeنمایش Routing Table و Default Gateway

چیزی که از این مرحله یاد گرفتم

  • ARP پلی بین Layer 3 و Layer 2 در شبکه‌های IPv4 است.
  • سیستم IP مقصد را دارد اما برای ارسال Ethernet Frame به MAC Address نیاز دارد.
  • با ip neigh می‌توانم ARP Table را در Linux ببینم.
  • برای مقصدهای خارج از شبکه محلی، ARP در نهایت MAC مربوط به Default Gateway را پیدا می‌کند.
  • ARP در IPv4 ذاتاً امن نیست و می‌تواند هدف حملاتی مثل ARP Spoofing قرار بگیرد.
