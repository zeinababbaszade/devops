ARP چیست؟

ARP مخفف Address Resolution Protocol است.

وظیفه ARP پیدا کردن MAC Address مربوط به یک IPv4 Address در شبکه محلی است.

ARP چه مشکلی را حل می‌کند؟

فرض کن Server A آدرس زیر را دارد:

Network 
IP: 192.168.1.10
MAC: AA:AA:AA:AA:AA:AA

و می‌خواهد برای 192.168.1.20 Packet ارسال کند.

IP مقصد را می‌داند، اما برای ارسال Frame در شبکه Ethernet به MAC مقصد نیاز دارد.

ARP این ارتباط را پیدا می‌کند.

فرآیند ARP

ARP Flow 
Who has 192.168.1.20?
        ↓
Broadcast
        ↓
192.168.1.20 replies:
I am AA:BB:CC:DD:EE:FF
        ↓
Store in ARP Table
        ↓
Send Ethernet Frame

ARP Table

سیستم عامل نتیجه ARP را برای مدتی Cache می‌کند. این اطلاعات در Linux در Neighbor Table قابل مشاهده است.

ARP در Linux

Terminal 
ip neigh

ممکن است خروجی شبیه این باشد:

Example 
192.168.1.1 dev ens160 lladdr 00:11:22:33:44:55 REACHABLE

ARP و Default Gateway

اگر مقصد خارج از شبکه محلی باشد، سیستم معمولاً Frame را به MAC Address مربوط به Default Gateway ارسال می‌کند.

Flow 
Application
     ↓
Destination IP
     ↓
Routing Table
     ↓
Default Gateway
     ↓
ARP → Gateway MAC
     ↓
Ethernet Frame

Troubleshooting با ARP

اگر Host در شبکه محلی قابل دسترسی نیست، می‌توانیم Neighbor Table را بررسی کنیم.

Linux 
ip neigh
ip route
⚠️ نکته امنیتی: ARP در IPv4 ذاتاً مکانیزم Authentication قوی ندارد و حملاتی مانند ARP Spoofing می‌توانند از ضعف‌های آن سوءاستفاده کنند.

🧪 تمرین عملی

اول Gateway سیستم را پیدا کن:
Terminal 
ip route

سپس:

Terminal 
ip neigh

MAC مربوط به Gateway را پیدا کن.

چیزی که یاد گرفتم

ARP پلی بین Layer 3 و Layer 2 در شبکه‌های IPv4 است. سیستم IP مقصد را دارد اما برای Ethernet به MAC Address نیاز دارد.

مرحله بعدی چیست؟

حالا که MAC و ARP را شناختیم، وقت آن است که خود IP Address و ساختار IPv4 را عمیق‌تر بررسی کنیم.
