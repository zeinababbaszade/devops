Process چیست؟

هر برنامه‌ای که در Linux در حال اجراست، معمولاً به شکل یک Process در سیستم دیده می‌شود. وقتی یک Terminal باز می‌کنیم، یک Shell اجرا می‌کنیم یا سرویسی مثل Nginx را راه‌اندازی می‌کنیم، Processهایی در سیستم ایجاد می‌شوند.

💡 در DevOps باید بتوانیم Processها را ببینیم، مصرف منابع آن‌ها را بررسی کنیم و در صورت نیاز یک Process مشکل‌دار را متوقف یا مدیریت کنیم.

PID چیست؟

هر Process یک شناسه عددی به نام PID دارد. این شناسه برای شناسایی Process در بسیاری از دستورات مدیریتی استفاده می‌شود.

Terminal
ps

برای دیدن Processهای مربوط به User فعلی می‌توانیم از ps استفاده کنیم.

Terminal
ps aux

بررسی Processها با ps

گزینه aux اطلاعات بیشتری درباره Processهای سیستم نشان می‌دهد؛ از جمله User، PID، میزان مصرف CPU و Memory و Command اجراشده.

Terminal
ps aux | head

برای پیدا کردن یک Process خاص می‌توانیم خروجی را با ابزارهایی مثل grep بررسی کنیم.

Terminal
ps aux | grep ssh

مانیتور زنده با top

دستور top اطلاعات Processها و مصرف منابع را به شکل زنده نمایش می‌دهد.

Terminal
top

برای خروج از top معمولاً کلید q را فشار می‌دهیم.

htop

htop یک ابزار تعاملی برای مشاهده Processهاست و معمولاً خواندن اطلاعات آن از top راحت‌تر است.

Terminal
sudo apt update
sudo apt install htop
htop
💡 اگر htop روی سیستم نصب نیست، نصب آن اجباری نیست؛ هدف این مرحله یادگیری مفهوم Process و ابزارهای مشاهده آن است.

متوقف کردن Process

برای ارسال Signal به یک Process از دستور kill استفاده می‌کنیم. ابتدا PID را پیدا می‌کنیم و سپس Signal مناسب را ارسال می‌کنیم.

Terminal
kill PID

اگر Process به شکل عادی متوقف نشد، Signal دیگری مثل -9 وجود دارد؛ اما نباید بدون دلیل از آن استفاده کرد.

Terminal
kill -9 PID
⚠️ قبل از اجرای kill یا مخصوصاً kill -9 مطمئن شو PID متعلق به Process موردنظر است. متوقف کردن یک Process مهم می‌تواند باعث اختلال سرویس شود.

Foreground و Background

بعضی Processها در Terminal در حالت Foreground اجرا می‌شوند و تا پایان آن‌ها کنترل Shell در اختیار برنامه است. با & می‌توان یک برنامه را در Background اجرا کرد.

Terminal
sleep 60 &

برای دیدن Jobهای Shell:

Terminal
jobs

تمرین عملی: Process Lab

🧪 تمرین

یک Process آزمایشی ایجاد و آن را بررسی کن:

Ubuntu Terminal
sleep 300 &
ps aux | grep '[s]leep 300'
top
# در top با q خارج شو
jobs
kill %1

هدف این تمرین این است که چرخه ساده اجرا → پیدا کردن → بررسی → متوقف کردن را تجربه کنی.

Process Cheat Sheet

Commandکاربرد
psنمایش Processهای مرتبط با Shell
ps auxنمایش گسترده Processهای سیستم
topمانیتور زنده Processها و منابع
htopنمایش تعاملی Processها
kill PIDارسال Signal به Process
jobsنمایش Jobهای Shell
command &اجرای Command در Background

چیزی که از این مرحله یاد گرفتم

  • هر برنامه در حال اجرا را می‌توان به شکل یک Process در نظر گرفت.
  • هر Process یک PID دارد.
  • با ps Processها را بررسی می‌کنم.
  • با top مصرف منابع را به‌صورت زنده می‌بینم.
  • با kill می‌توانم Signal ارسال کنم.
