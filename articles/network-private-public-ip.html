Private IP & Public IP

تفاوت Private و Public IP، محدوده‌های Private، NAT و نحوه استفاده از آن‌ها در شبکه‌های Server و DevOps.

Private IP چیست؟

Private IP برای استفاده در شبکه‌های داخلی طراحی شده و مستقیماً برای ارتباط عمومی روی Internet استفاده نمی‌شود.

محدوده‌های Private IPv4

Range Subnet
10.0.0.0 – 10.255.255.255 10.0.0.0/8
172.16.0.0 – 172.31.255.255 172.16.0.0/12
192.168.0.0 – 192.168.255.255 192.168.0.0/16

Public IP چیست؟

Public IP آدرسی است که می‌تواند در Internet Routing عمومی استفاده شود.

Serverهایی که مستقیماً از Internet قابل دسترسی هستند ممکن است Public IP داشته باشند.

NAT چیست؟

NAT مخفف Network Address Translation است.

NAT به شبکه‌های Private اجازه می‌دهد از طریق یک یا چند Public IP با Internet ارتباط برقرار کنند.

Example 
Private Network

192.168.1.10
192.168.1.11
192.168.1.12
       ↓
      NAT
       ↓
Public IP
       ↓
   Internet

مثال Server

فرض کن یک Web Server داخل شبکه شرکت داری:

Internal Network 
Server:
10.10.10.20

Database:
10.10.10.30

Monitoring:
10.10.10.40

این Serverها می‌توانند با Private IP با یکدیگر ارتباط داشته باشند.

چرا برای DevOps مهم است؟

در VMware، Docker، Kubernetes و Cloud دائماً با Private Networkها مواجه می‌شوی.

مثلاً در یک معماری معمول:

Architecture 
Internet
   ↓
Load Balancer
   ↓
Private Network
   ↓
Application Servers
   ↓
Database

معمولاً Database نباید مستقیماً روی Public Internet قرار داشته باشد.

⚠️ نکته امنیتی: Public بودن یک IP به خودی خود به معنی ناامن بودن Server نیست، اما سطح دسترسی و Attack Surface را افزایش می‌دهد و باید Firewall و Access Control مناسب وجود داشته باشد.

🧪 تمرین

IP سیستم خودت را پیدا کن:
Linux 
ip -br addr

مشخص کن IP سیستم Private است یا Public.

چیزی که یاد گرفتم

Private IP برای شبکه‌های داخلی و Public IP برای ارتباطات قابل Route در Internet استفاده می‌شود. NAT یکی از روش‌های اصلی ارتباط شبکه‌های Private با Internet است.

مرحله بعدی چیست؟

حالا باید یاد بگیریم چطور یک شبکه بزرگ را به شبکه‌های کوچک‌تر تقسیم کنیم. اینجا Subnetting وارد می‌شود.
