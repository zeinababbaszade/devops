Private و Public IP چیست؟

همه IP Addressهایی که در شبکه‌ها استفاده می‌شوند مستقیماً روی اینترنت Route نمی‌شوند. در IPv4 یک سری Range مخصوص شبکه‌های خصوصی وجود دارد.

Private IP Ranges

Rangeمحدوده
10.0.0.0/810.0.0.0 تا 10.255.255.255
172.16.0.0/12172.16.0.0 تا 172.31.255.255
192.168.0.0/16192.168.0.0 تا 192.168.255.255
💡 آدرس‌های Private معمولاً برای شبکه‌های داخلی سازمان‌ها، خانه‌ها، Serverهای داخلی و Cloud Networkها استفاده می‌شوند.

Public IP

Public IP آدرسی است که در فضای عمومی Internet قابل Route شدن است و توسط سازمان‌های مربوط به Address Allocation مدیریت می‌شود.

یک Server که مستقیماً از اینترنت قابل دسترسی است ممکن است Public IP داشته باشد.

NAT چیست؟

Network Address Translation مکانیزمی است که می‌تواند آدرس‌های IP را هنگام عبور از یک Gateway ترجمه کند.

یکی از کاربردهای رایج NAT این است که چند سیستم با Private IP بتوانند از طریق یک Public IP به اینترنت دسترسی پیدا کنند.

Example
PC 1: 192.168.1.10
PC 2: 192.168.1.11
PC 3: 192.168.1.12

یک سناریوی واقعی

فرض کن لپ‌تاپ، موبایل و چند سیستم دیگر در شبکه خانه IPهای Private دارند. Router خانه می‌تواند Traffic آن‌ها را از طریق یک Public IP به اینترنت ارسال کند.

اهمیت برای DevOps

در DevOps دائماً با تفاوت بین شبکه‌های داخلی و عمومی روبه‌رو می‌شویم. برای مثال:

  • Database ممکن است Private باشد.
  • Application Server ممکن است در Private Network باشد.
  • Load Balancer ممکن است Public باشد.
  • Monitoring Server ممکن است داخل شبکه سازمان باشد.
  • Cloud Security Group ممکن است دسترسی Public را محدود کند.

بررسی در Linux

Ubuntu
ip addr
ip route

با این دستورات می‌توان Interfaceها، IPها و Routing Table را بررسی کرد.

چیزی که یاد گرفتم

  • Private IP برای شبکه‌های داخلی استفاده می‌شود.
  • Public IP در Internet قابل Route شدن است.
  • NAT می‌تواند آدرس‌ها را هنگام عبور از Gateway ترجمه کند.
  • Private Network یکی از مفاهیم مهم در Cloud و DevOps است.
