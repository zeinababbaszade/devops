IP Address چیست؟

IP Address یک آدرس منطقی برای شناسایی یک Interface یا Host در شبکه است.

IP به سیستم‌ها اجازه می‌دهد بدانند Packet باید از کجا ارسال شود و به کجا برسد.

IPv4

IPv4 دارای 32 بیت است و معمولاً به چهار Octet نمایش داده می‌شود.

Example 
192.168.10.25

هر بخش می‌تواند عددی بین 0 تا 255 باشد.

IPv4 و Binary

در سطح کامپیوتر IP به صورت Binary ذخیره و پردازش می‌شود.

Example 
192 = 11000000
168 = 10101000
10  = 00001010
25  = 00011001

Network و Host

یک IP معمولاً از دو بخش مفهومی تشکیل می‌شود:

  • Network Portion
  • Host Portion

Subnet Mask مشخص می‌کند کدام قسمت مربوط به Network و کدام قسمت مربوط به Host است.

Subnet Mask

مثلاً:

Example 
IP:
192.168.1.20

Mask:
255.255.255.0

در این حالت Network معمولاً 192.168.1.0 است.

IPv6

IPv6 برای حل محدودیت فضای IPv4 طراحی شده و از آدرس‌های 128 بیتی استفاده می‌کند.

Example 
2001:db8::1

IP در Linux

Terminal 
ip addr
ip -br addr

برای دیدن IP یک Interface خاص:

Terminal 
ip addr show ens160

یک نکته مهم برای DevOps

وقتی با Docker، Kubernetes، VMware یا Cloud کار می‌کنی، تقریباً دائماً با IP Address سروکار خواهی داشت.

🧪 تمرین

IP سیستم Ubuntu خودت را پیدا کن و موارد زیر را مشخص کن:
  • IP Address
  • Subnet Mask یا Prefix
  • Interface
  • Network
  • Gateway
Commands 
ip -br addr
ip route

چیزی که یاد گرفتم

IP آدرس منطقی سیستم در شبکه است و IPv4 از 32 بیت تشکیل شده است. Subnet Mask یا Prefix مشخص می‌کند کدام قسمت IP متعلق به Network است.

مرحله بعدی چیست؟

حالا باید تفاوت Private IP و Public IP را یاد بگیریم؛ مفهومی که در Server، Cloud و Internet بسیار مهم است.
