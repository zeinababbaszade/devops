MAC Address چیست؟

MAC Address یک شناسه برای Network Interface است که در شبکه‌های محلی Ethernet بسیار مهم است.

یک MAC Address معمولاً به‌صورت شش بخش Hexadecimal نمایش داده می‌شود.

Example
00:1A:2B:3C:4D:5E

IP Address چیست؟

IP Address برای شناسایی منطقی یک Host یا Interface در شبکه استفاده می‌شود.

در IPv4 آدرس‌ها 32 بیت هستند و معمولاً به‌صورت چهار عدد جداشده با نقطه نمایش داده می‌شوند.

Example
192.168.1.20

Network Interface

در Linux هر کارت شبکه یا Interface می‌تواند MAC Address و یک یا چند IP Address داشته باشد.

Terminal
ip link
ip addr

نمونه خروجی

Example
2: ens160: <BROADCAST,MULTICAST,UP,LOWER_UP>

link/ether 00:0c:29:12:34:56

inet 192.168.1.20/24

در این مثال:

  • ens160 نام Interface است.
  • 00:0c:29:12:34:56 MAC Address است.
  • 192.168.1.20 IP Address است.

Loopback

Interface معروف lo برای ارتباط داخلی خود سیستم استفاده می‌شود.

Terminal
ip addr show lo

آدرس معروف Loopback در IPv4 برابر با 127.0.0.1 است.

مشاهده IP و MAC در Linux

Terminal
ip addr
ip link
ip -br addr
💡 در Linux مدرن بهتر است به جای ابزارهای قدیمی مانند ifconfig با ابزار ip کار کنی.

MAC & IP Cheat Sheet

Commandکاربرد
ip addrنمایش کامل IP و اطلاعات Interfaceها
ip linkنمایش Interfaceها و MAC Address
ip -br addrنمایش خلاصه و مرتب IPها
ip addr show loنمایش اطلاعات Interface Loopback

چیزی که از این مرحله یاد گرفتم

  • MAC Address شناسه ثابت یک Interface در Layer 2 است.
  • IP Address یک Logical Address در Layer 3 است و برای Routing استفاده می‌شود.
  • هر Interface می‌تواند هم MAC و هم یک یا چند IP داشته باشد.
  • Interface lo و آدرس 127.0.0.1 برای ارتباط داخلی خود سیستم است.
  • در Linux مدرن باید از دستور ip به‌جای ifconfig استفاده کنم.

مرحله بعدی چیست؟

🔗 ARP

حالا باید بفهمم وقتی یک سیستم IP مقصد را می‌داند، چطور MAC Address مربوط به آن را در شبکه محلی پیدا می‌کند. اینجاست که ARP وارد می‌شود.
