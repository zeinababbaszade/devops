MAC Address & IP Address

دو مفهوم پایه‌ای شبکه؛ MAC برای شناسایی Interface در شبکه محلی و IP برای Addressing و Routing بین شبکه‌ها.

MAC Address چیست؟

MAC Address یک شناسه برای Network Interface است که در شبکه‌های محلی Ethernet بسیار مهم است.

یک MAC Address معمولاً به صورت شش بخش hexadecimal نمایش داده می‌شود.

Example 
00:1A:2B:3C:4D:5E

IP Address چیست؟

IP Address برای شناسایی منطقی یک Host یا Interface در شبکه استفاده می‌شود.

در IPv4 آدرس‌ها 32 بیت هستند و معمولاً به صورت چهار عدد جداشده با نقطه نمایش داده می‌شوند.

Example 
192.168.1.20

MAC در برابر IP

MAC IP
شناسه Interface Logical Address
Layer 2 Layer 3
شبکه محلی Routing بین شبکه‌ها
معمولاً با Hexadecimal IPv4 با Decimal

Network Interface

در Linux هر کارت شبکه یا Interface می‌تواند MAC Address و یک یا چند IP Address داشته باشد.

Linux 
ip link
ip addr

نمونه خروجی

Example 
2: ens160: <BROADCAST,MULTICAST,UP,LOWER_UP>

link/ether 00:0c:29:12:34:56

inet 192.168.1.20/24

در این مثال:

  • ens160 نام Interface است.
  • 00:0c:29:12:34:56 MAC Address است.
  • 192.168.1.20 IP Address است.

Loopback

Interface معروف lo برای ارتباط داخلی خود سیستم استفاده می‌شود.

Linux 
ip addr show lo

آدرس معروف Loopback در IPv4 برابر با 127.0.0.1 است.

مشاهده IP و MAC

Terminal 
ip addr
ip link
ip -br addr
💡 نکته: در Linux مدرن بهتر است به جای ابزارهای قدیمی مانند ifconfig با ابزار ip کار کنی.

🧪 تمرین عملی

روی Ubuntu اجرا کن:
Terminal 
ip -br addr
ip link
ip addr show lo

نام Interface، MAC و IPv4 سیستم خودت را پیدا کن.

چیزی که یاد گرفتم

MAC بیشتر در شبکه محلی و Layer 2 اهمیت دارد، در حالی که IP برای Addressing و Routing در Layer 3 استفاده می‌شود.

مرحله بعدی چیست؟

حالا باید بفهمیم وقتی یک سیستم IP مقصد را می‌داند، چطور MAC Address مربوط به آن را در شبکه محلی پیدا می‌کند. اینجاست که ARP وارد می‌شود.
