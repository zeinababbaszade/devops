فایل‌سیستم Linux چیست؟

یکی از تفاوت‌های مهم Linux با Windows نحوه سازمان‌دهی فایل‌ها و دایرکتوری‌ها است.

در Linux تقریباً همه چیز از یک نقطه شروع می‌شود که به آن Root Directory گفته می‌شود.

این دایرکتوری با علامت / نمایش داده می‌شود.

بنابراین ساختار فایل‌سیستم لینوکس را می‌توانیم به شکل یک درخت تصور کنیم: 

/
├── bin
├── boot
├── dev
├── etc
├── home
├── lib
├── media
├── mnt
├── opt
├── proc
├── root
├── run
├── sbin
├── srv
├── sys
├── tmp
├── usr
└── var

1. دایرکتوری / یا Root Directory

علامت / ریشه فایل‌سیستم Linux است.

تمام دایرکتوری‌های اصلی Linux در نهایت زیر / قرار دارند.

برای رفتن به Root Directory می‌توانیم از دستور زیر استفاده کنیم: 

cd /

سپس با دستور زیر محتویات آن را مشاهده می‌کنیم: 

ls -la
نکته مهم:

/ با کاربر root یکی نیست.

/ یک دایرکتوری است، اما root نام کاربر قدرتمند سیستم Linux است.

2. دایرکتوری /home

دایرکتوری /home محل قرارگیری فایل‌های کاربران عادی سیستم است.

برای مثال اگر کاربری با نام zeinab داشته باشیم، معمولاً Home Directory او چیزی شبیه این خواهد بود: 

/home/zeinab

می‌توانیم با دستور زیر وارد Home خودمان شویم: 

cd ~

یا: 

cd /home/zeinab

البته نام کاربر در سیستم شما ممکن است متفاوت باشد.

3. دایرکتوری /etc

دایرکتوری /etc یکی از مهم‌ترین قسمت‌های Linux است.

بسیاری از فایل‌های Configuration یا تنظیمات سیستم و سرویس‌ها در این دایرکتوری قرار دارند.

برای مشاهده محتویات آن: 

ls -la /etc

بعدها وقتی وارد مباحثی مثل SSH، Nginx، Docker و سرویس‌های Linux شویم، زیاد با /etc سر و کار خواهیم داشت.

4. دایرکتوری /var

/var برای اطلاعاتی استفاده می‌شود که در طول اجرای سیستم یا برنامه‌ها مرتب تغییر می‌کنند.

یکی از مهم‌ترین قسمت‌های آن: 

/var/log

است که محل قرارگیری بسیاری از Logهای سیستم و سرویس‌هاست.

برای مشاهده Logها: 

ls -la /var/log

این قسمت در آینده برای Troubleshooting و مانیتورینگ خیلی مهم خواهد بود.

5. دایرکتوری /tmp

/tmp برای فایل‌های موقتی استفاده می‌شود.

برنامه‌ها می‌توانند در این قسمت فایل‌هایی ایجاد کنند که فقط برای مدت کوتاهی مورد نیاز هستند.

برای مشاهده محتویات: 

ls -la /tmp
نکته:

فایل‌های موجود در /tmp را نباید بدون شناخت کامل سیستم به صورت دستی حذف کرد.

6. دایرکتوری /usr

/usr شامل بخش بزرگی از برنامه‌ها، کتابخانه‌ها و فایل‌های مربوط به نرم‌افزارهای سیستم است.

برای مثال: 

/usr/bin
/usr/sbin
/usr/lib
/usr/share

بعداً هنگام کار با Package Managerها و نصب نرم‌افزارها بیشتر با این ساختار آشنا خواهیم شد.

7. دایرکتوری /opt

/opt معمولاً برای نصب نرم‌افزارهای اضافی و Third-party استفاده می‌شود.

برای مثال ممکن است یک نرم‌افزار خاص را در مسیری مانند زیر نصب کنیم: 

/opt/my-application

در محیط‌های DevOps ممکن است هنگام نصب بعضی نرم‌افزارها و Applicationهای خاص با این مسیر مواجه شویم.

دستورات کاربردی برای بررسی File System

مشاهده مسیر فعلی

pwd

مشاهده محتویات یک دایرکتوری

ls

مشاهده جزئیات

ls -la

رفتن به Root

cd /

رفتن به Home

cd ~

مشاهده ساختار دایرکتوری‌های Root

ls -la /

مشاهده فضای دیسک

df -h

دستور df -h برای مشاهده میزان فضای استفاده‌شده و آزاد فایل‌سیستم‌ها بسیار کاربردی است.

تمرین عملی روی Ubuntu

حالا نوبت تمرین است. این دستورات را روی Ubuntu خودت اجرا کن.

مرحله 1 — مسیر فعلی

pwd

مرحله 2 — رفتن به Root

cd /
pwd

باید ببینی مسیر فعلی: 

/

مرحله 3 — مشاهده دایرکتوری‌ها

ls -la

مرحله 4 — بررسی Home

ls -la /home

مرحله 5 — بررسی Logها

ls -la /var/log

مرحله 6 — بررسی فضای دیسک

df -h

مرحله 7 — برگشت به Home

cd ~
pwd
تمرین پیشنهادی:

قبل از اینکه مقاله بعدی را شروع کنیم، تمام دستورات بالا را روی Ubuntu اجرا کن و خروجی آن‌ها را بررسی کن.

هدف این نیست که فقط دستورات را حفظ کنیم؛ می‌خواهیم واقعاً با محیط Linux کار کنیم.

Cheat Sheet

مسیر کاربرد
/ ریشه فایل‌سیستم
/home فایل‌های کاربران
/etc فایل‌های Configuration
/var داده‌های متغیر و Logها
/tmp فایل‌های موقت
/usr برنامه‌ها و فایل‌های سیستم
/opt نرم‌افزارهای اضافی
