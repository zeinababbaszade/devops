چرا Text Processing مهم است؟

در Linux بسیاری از خروجی‌ها، Configهای سرویس‌ها و Logها به‌صورت متنی ذخیره می‌شوند. برای اینکه بتوانیم اطلاعات مفید را از دل این متن‌ها پیدا کنیم، به ابزارهایی نیاز داریم که بتوانند متن را جستجو، فیلتر و پردازش کنند.

در محیط‌های DevOps، این مهارت یکی از پرکاربردترین مهارت‌هاست؛ چه هنگام بررسی Logهای یک سرویس، چه هنگام استخراج اطلاعات از خروجی دستوراتی مثل ps یا df.

💡 هدف این مقاله یادگیری کامل Regex یا سینتکس پیشرفته sed و awk نیست؛ هدف این است که با کاربردهای روزمره‌ی این ابزارها در کار با سرور آشنا شوم.

جستجو در متن با grep

دستور grep برای پیدا کردن خط‌هایی از یک فایل یا خروجی که با یک الگوی خاص Match می‌شوند استفاده می‌شود.

Terminal
grep "error" app.log

این دستور تمام خط‌هایی از فایل app.log را که شامل کلمه error هستند نمایش می‌دهد.

برای جستجو بدون حساسیت به بزرگ و کوچک بودن حروف:

Terminal
grep -i "error" app.log

برای نمایش شماره خط در کنار نتیجه:

Terminal
grep -n "error" app.log

و برای جستجوی بازگشتی داخل چند فایل و پوشه:

Terminal
grep -rn "error" /var/log/

همچنین می‌توانیم grep را با Pipe به خروجی دستورات دیگر وصل کنیم؛ مثلاً برای پیدا کردن یک Process خاص:

Terminal
ps aux | grep nginx

کار با ستون‌ها با cut

دستور cut برای جدا کردن بخشی از هر خط، معمولاً بر اساس یک جداکننده (Delimiter) استفاده می‌شود.

فرض کنیم فایل users.txt این‌طور است:

users.txt
ali:1001:/home/ali
sara:1002:/home/sara

برای گرفتن فقط ستون اول (نام کاربر):

Terminal
cut -d ":" -f 1 users.txt

گزینه -d جداکننده و -f شماره ستون موردنظر را مشخص می‌کند.

مرتب‌سازی با sort

دستور sort خطوط ورودی را به‌صورت مرتب‌شده نمایش می‌دهد.

Terminal
sort users.txt

برای مرتب‌سازی عددی:

Terminal
sort -n numbers.txt

و برای مرتب‌سازی معکوس (نزولی):

Terminal
sort -r users.txt

حذف موارد تکراری با uniq

دستور uniq خطوط تکراری متوالی را حذف می‌کند. معمولاً قبل از آن باید از sort استفاده کرد، چون uniq فقط تکرارهای پشت‌سرهم را تشخیص می‌دهد.

Terminal
sort access.log | uniq

برای دیدن تعداد تکرار هر خط:

Terminal
sort access.log | uniq -c
💡 کاربرد رایج: ترکیب sort | uniq -c | sort -nr یکی از پرکاربردترین الگوها برای پیدا کردن پرتکرارترین خطوط یک Log است؛ مثلاً پیدا کردن پرتکرارترین IPهایی که به سرور درخواست زده‌اند.

ویرایش متن با sed

دستور sed (Stream Editor) برای جستجو و جایگزینی متن استفاده می‌شود؛ بدون اینکه لازم باشد فایل را در یک ویرایشگر باز کنیم.

برای جایگزینی اولین Match در هر خط:

Terminal
sed 's/error/ERROR/' app.log

برای جایگزینی همه Matchها در هر خط، از گزینه g (Global) استفاده می‌کنیم:

Terminal
sed 's/error/ERROR/g' app.log

به‌طور پیش‌فرض، sed فایل اصلی را تغییر نمی‌دهد و فقط نتیجه را در خروجی نشان می‌دهد. برای ویرایش مستقیم فایل از گزینه -i استفاده می‌شود:

Terminal
sed -i 's/error/ERROR/g' app.log
⚠️ گزینه -i فایل را مستقیماً تغییر می‌دهد و این تغییر برگشت‌پذیر نیست. قبل از استفاده از آن روی فایل‌های مهم، حتماً یک نسخه Backup تهیه کن.

پردازش ستونی با awk

awk یک ابزار قدرتمند برای پردازش متن بر اساس ستون‌هاست و از cut انعطاف‌پذیرتر است، چون می‌تواند شرط، محاسبه و قالب‌بندی هم انجام دهد.

برای چاپ ستون اول هر خط:

Terminal
awk '{print $1}' access.log

awk به‌طور پیش‌فرض هر خط را بر اساس فاصله (Space) به ستون‌های $1، $2 و... تقسیم می‌کند.

برای مشخص کردن جداکننده دلخواه (مثلاً برای فایل با جداکننده :):

Terminal
awk -F ":" '{print $1}' users.txt

و برای اضافه کردن شرط، مثلاً فقط خط‌هایی که ستون سوم آن‌ها بزرگ‌تر از 100 است:

Terminal
awk '$3 > 100 {print $0}' report.txt

آشنایی مقدماتی با Regex

Regex (Regular Expression) یک روش نوشتن الگو برای جستجوی متن است. اکثر ابزارهایی که تا اینجا دیدیم (grep، sed و awk) از Regex پشتیبانی می‌کنند.

نمادمعنی
.هر یک کاراکتر دلخواه
*صفر یا بیشتر از کاراکتر قبلی
^ابتدای خط
$انتهای خط
[abc]یکی از کاراکترهای داخل براکت

مثال: پیدا کردن خط‌هایی که با Error شروع می‌شوند:

Terminal
grep "^Error" app.log
💡 برای شروع کار روزمره، نیازی نیست همه قوانین Regex را حفظ باشیم. همین چند نماد پایه برای بیشتر کارهای روزمره کافی است و بقیه را در عمل و بر اساس نیاز یاد می‌گیریم.

ترکیب ابزارها با Pipe

قدرت واقعی این ابزارها زمانی مشخص می‌شود که آن‌ها را با | (Pipe) به هم وصل کنیم. مثلاً برای پیدا کردن پرتکرارترین IPهایی که به یک سرور وب درخواست زده‌اند:

Terminal
cat access.log | awk '{print $1}' | sort | uniq -c | sort -nr | head

این دستور به ترتیب:

  • ستون اول (IP) هر خط را استخراج می‌کند
  • خروجی را مرتب می‌کند
  • تعداد تکرار هر IP را می‌شمارد
  • بر اساس بیشترین تکرار مرتب می‌کند
  • فقط چند نتیجه اول را نمایش می‌دهد

تمرین عملی: Text Processing Lab

🧪 تمرین

یک فایل Log نمونه بساز و روی آن تمرین کن:

Ubuntu Terminal
cd ~/devops-lab
mkdir -p linux/textproc
cd linux/textproc

echo "192.168.1.1 - - GET /index.html 200" > access.log
echo "192.168.1.2 - - GET /login.html 200" >> access.log
echo "192.168.1.1 - - GET /index.html 404" >> access.log
echo "192.168.1.3 - - GET /index.html 500" >> access.log

grep "404" access.log

awk '{print $1}' access.log | sort | uniq -c | sort -nr

sed 's/200/OK/' access.log

سعی کن قبل از اجرای هر دستور حدس بزنی خروجی چه چیزی خواهد بود، سپس نتیجه واقعی را با حدس خودت مقایسه کن.
