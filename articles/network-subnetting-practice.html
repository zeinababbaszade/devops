Subnetting چیست؟

Subnetting یعنی تقسیم یک Network بزرگ‌تر به چند Network کوچک‌تر. این کار باعث مدیریت بهتر IP Addressها، کاهش Broadcast Domain و استفاده بهتر از Address Space می‌شود.

💡 یکی از مهم‌ترین مهارت‌های Networking برای DevOps این است که بتوانی سریع Network، Broadcast و Host Range را از روی Prefix پیدا کنی.

فرمول تعداد Host

IPv4 دارای 32 بیت است. اگر Prefix برابر /24 باشد، 8 بیت برای Host باقی می‌ماند.

Formula
Host Bits = 32 - Prefix

Usable Hosts = 2^HostBits - 2

برای /24:

Calculation
32 - 24 = 8

2^8 - 2 = 254 Hosts

مثال /24

Network
192.168.1.0/24
مورد مقدار
Network 192.168.1.0
First Host 192.168.1.1
Last Host 192.168.1.254
Broadcast 192.168.1.255
Usable Hosts 254

مثال /26

در /26 شش بیت برای Host داریم:

Calculation
32 - 26 = 6

2^6 - 2 = 62 Hosts

یک /24 را می‌توان به چهار /26 تقسیم کرد:

Subnets
192.168.1.0/26
192.168.1.64/26
192.168.1.128/26
192.168.1.192/26

مثال /27

در /27 پنج بیت Host داریم:

Calculation
32 - 27 = 5

2^5 - 2 = 30 Hosts

Block Size برابر 32 است:

Subnets
192.168.1.0/27
192.168.1.32/27
192.168.1.64/27
192.168.1.96/27
192.168.1.128/27
192.168.1.160/27
192.168.1.192/27
192.168.1.224/27

Block Size چیست؟

Block Size به ما کمک می‌کند Network Addressهای پشت سر هم را سریع پیدا کنیم.

برای مثال در /26:

Block Size
256 - 192 = 64

چون Subnet Mask برابر 255.255.255.192 است، فاصله Networkها 64 خواهد بود.

Subnetting در Linux

برای بررسی IP و Prefix روی Ubuntu می‌توان از:

Terminal
ip addr

و برای بررسی Route:

Terminal
ip route

همچنین ابزار ipcalc برای محاسبات Subnet بسیار مفید است.

Ubuntu
sudo apt install ipcalc

ipcalc 192.168.10.77/27

Subnetting در DevOps

  • Cloud VPC / VNet
  • Docker Networks
  • Kubernetes Networking
  • Server Segmentation
  • Monitoring Networks
  • Firewall Rules
  • Database Networks
  • Production / Development Separation
⚠️ در محیط Production، تغییر Subnet یا IP Range بدون بررسی Routing، Firewall و وابستگی سرویس‌ها می‌تواند باعث قطعی سرویس شود.

Subnetting Cheat Sheet

Prefix Usable Hosts Subnet Mask
/24 254 255.255.255.0
/25 126 255.255.255.128
/26 62 255.255.255.192
/27 30 255.255.255.224
/28 14 255.255.255.240

چیزی که از این مرحله یاد گرفتم

  • Prefix تعداد Network و Host Bits را مشخص می‌کند.
  • تعداد Hostها از تعداد Host Bits به دست می‌آید.
  • با Block Size می‌توان Subnetهای متوالی را سریع پیدا کرد.
  • Subnetting یکی از پایه‌های مهم Networking در DevOps است.
  • تمرین زیاد باعث می‌شود محاسبات Subnetting سریع‌تر انجام شوند.
